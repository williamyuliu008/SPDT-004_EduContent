## 一、文档概况与项目对应

教学建模文档（50KB，14个章节）系统构建了**从"六根六尘外部传递"到"五蕴内部认知"到"脑科学升级"到"教育认知工程"**的完整理论体系。

PT-038 TextExperience 是一个已经跑通管线的具体项目，涵盖了教学建模文档理论的一个子集（音频+视觉+Flashcard）。

本文分析两者的**共鸣点、补充点、启发点**，并指出 PT-038 当前尚未覆盖的空白领域。

## 二、已共鸣：PT-038 已在实践的核心对应

### 2.1 六根六尘 → PT-038 格式分工

| 六尘通道 | 教学建模理论定位 | PT-038 已有实现 |
|---|---|---|
| **声尘**（主） | 知识传递主叙事线，音频优先 | ✅ 微剧本音频（primary format） |
| **色尘**（辅） | 结构化视觉锚点，降工作记忆负载 | ✅ 电子书关键词标注 + Flashcard 排版 |
| 触尘 | 物理实验触感，冷热等 | ❌ 标注边界，暂不覆盖 |
| 身根/肢体尘 | 教师动作演示 | ❌ 大模型边界，标注"暂缺" |
| 鼻/味尘 | 化学实验气味，低年级感知 | ❌ 标注边界，暂不覆盖 |

**核心共鸣**：教学建模文档明确说"教师传递信息渠道以音频为主，视觉其次"，PT-038 选择微剧本音频作为第一格式，与此完全吻合。PT-038 的"格式分工"本身就是六根六尘模型在产品层的具体化。

**差异**：文档是从"教师视角"建模（教师决定给什么尘），PT-038 是"内容设计视角"（设计者决定生产什么尘）。但两者的功能映射高度一致。

---

### 2.2 五蕴认知链 → PT-038 已有覆盖

| 五蕴阶段 | 认知任务 | PT-038 已有实现 | 说明 |
|---|---|---|---|
| **色蕴** | 感官接收外界信息 | 微剧本音频 + 电子书文本 | 声尘+色尘输入 |
| **受蕴** | 即时情绪反应（苦/乐/共鸣） | 核心问题驱动的认知冲突设计 | "你觉得X，但真相是Y" |
| **想蕴** | 表象分别 + 意义初判 | 知识链 chain_id 结构化 | 把散的输入拼成"这是什么" |
| **行蕴** | 主动造作的深加工 | **Flashcard 主动检索** | PT-038 最强行蕴实现 |
| **识蕴** | 稳定内化的认知结果 | Flashcard 复习后的知识稳固 | 通过重复间隔检索固化 |

**关键洞察**：教学建模文档指出"Flashcard 属于行蕴工具"，PT-038 的卡片体系恰好填补了其他现有教育方案最容易缺失的一环——**"主动检索"触发的前额叶-海马体记忆巩固回路**。

文档§5明确说："很多学生'上课听着懂，下课就忘'，就是卡在想蕴没启动行蕴。" PT-038 用 Flashcard 强制行蕴激活，这是设计上的精准卡位。

---

### 2.3 类比法 → PT-038 的 Type I-IV 知识分类

教学建模文档§12-13给出的知识分类框架：

| 类型 | 描述 | 类比适用性 |
|---|---|---|
| **I型** | 结构清晰 + 日常有同构体 | ✅ 优先用类比 |
| **II型** | 部分清晰 + 含领域假设 | ⚠️ 受限类比 + 差异标注 |
| **III型** | 纯形式化，无日常同构 | ❌ 关闭类比，用结构推导 |
| **IV型** | 具象事实性知识 | ❌ 不需要类比 |

PT-038 在配置包设计中已有类似的**chain_type 判断**（因果型/对比型/并列型/时间型），以及**一简对多篆速查表的译篆类比桥接**。文档提供了更细粒度的分类维度和更明确的工程规则（"必须先做结构清单提取"、"强制加差异红框"）。

**启发点**：PT-038 的 chain_type 是从"叙事结构"角度分类（因果/对比/并列），文档的 Type I-IV 是从"类比适用性"角度分类。两者可以叠加：chain_type 解决"知识链怎么讲"，knowledge_type 解决"这个知识点能不能用类比"。

**下一步**：在 meta.json 中增加 `knowledge_type` 字段（I/II/III/IV），card_generator 增加类比生成逻辑（仅对 I/II 型激活）。

## 三、补充点：PT-038 尚未覆盖的教学建模设计

### 3.1 缺失1：声尘的精细化设计（语气/节奏/停顿）

教学建模文档§8-9 展示了"逐字稿"级别的声尘设计：

```text
# 文档中的声尘示例（明喻教学）
（慢速，重读"像"，停顿1秒）
"看这句：弯弯的月亮 **像** 小船。（停顿1秒）
  注意听——有一个特别的词：**像**！（重读，拉长）
  只要有'像'，我们就知道这是——**明喻**！"
```

**PT-038 当前状态**：微剧本脚本有旁白文本，但没有精细化的语气标注（重读/停顿/情绪）。这对于音频驱动的产品尤其重要。

**工程缺口**：SOP 应增加"声尘设计规范"，要求每条核心讲解旁白注明：
- 语速（正常/稍慢/重读强调）
- 停顿位置和时长
- 情绪标注（好奇/沉重/疑问/庄严）
- 目标触发的受蕴类型（乐受/共鸣苦受/好奇）

### 3.2 缺失2：五蕴卡点诊断设计

教学建模文档§7 的30秒微流程展示了五蕴的每一步都可以观测和诊断：

| 五蕴阶段 | 卡点表现 | 干预方式 |
|---|---|---|
| 色蕴 | 走神、记不住关键词 | 增强色尘（关键词放大/重复声尘） |
| 受蕴 | 厌烦/漠然（苦受） | 换认知冲突声尘/生活共鸣唤醒 |
| 想蕴 | "好像懂了"但答错 | 追问暴露偏差，引导行蕴纠偏 |
| 行蕴 | 不愿主动输出 | 降低任务门槛（填空替代问答） |
| 识蕴 | 能背定义但不会用 | 加远迁移练习，闭环检验 |

**PT-038 当前状态**：Flashcard 有基本的"判断对错"功能，但没有基于五蕴卡点诊断的自适应反馈机制。

**工程缺口**：Flashcard generator 未来可增加"五蕴卡点标记"字段，针对不同卡点生成不同类型的 feedback 文本。

### 3.3 缺失3：理科场景的六尘示范（对PT-038的文科扩展价值）

教学建模文档用牛顿第一定律（理科）和隐喻手法（文科）两个案例做对比，说明"理科重眼耳逻辑协同，文科重身意经验协同"。

**对PT-038的书法/古汉语备考场景的启发**：
- 书法学科兼具理科（空间结构、笔法力学）和文科（审美判断、文化语境）特性
- "译篆/句读"类似理科的形式化（结构关系清晰），可以用类比通道（I/II型）
- "书法审美/史学评判"类似文科（经验感知、情感共鸣），应重受蕴和身根
- 这意味着 PT-038 的配置包设计可能需要区分**不同考试科目用不同的六尘侧重**

## 四、启发点：文档给 PT-038 的新增设计方向

### 4.1 启发1：大模型作为"六尘分解器"的定位 → PT-038 的 AI 管线哲学

文档§8给大模型在六根六尘框架下的定位是：

> "大模型天然擅长**符号处理、逻辑拆解、语言生成、结构化输出**，正好对应'把知识点拆成可感知的色尘（文本/图表描述）、声尘（讲解/追问语言）'"

PT-038 的 Python 管线本质上已经在做这件事：
- episode .py 文件 = 知识点结构化（六尘的色尘部分）
- card_generator.py = 声尘（Flashcard 的 front/answer 逻辑）
- ebook_generator.py = 色尘的组装输出

**深化方向**：PT-038 的下一阶段可以让大模型**直接生成六尘分解**，而非人工写 episode.py——输入知识点，输出"色尘（结构板书）+ 声尘（讲解逐字稿）+ 类比通道（如适用）+ 五蕴串链"，再接 Flashcard 生成。

### 4.2 启发2：双重编码 → 强化色尘与声尘的语义对齐

文档§11（双重编码理论）明确规则：

> "每生成一个声尘（讲解某概念），必须同步生成一个**语义对齐的色尘**（结构图/关键词层级/空间示意），且标注'对齐点'。禁止'声尘讲A，色尘放无关B图'。"

**PT-038 当前缺口**：微剧本（声尘）和 Flashcard（视觉）之间的语义对齐没有显式标注。

**工程改进**：card_generator 应在生成卡片前，先读取对应 episode 的"核心问题"和"关键结论"，在 Flashcard 的 answer 中明确引用"参照本集核心问题"或"参照知识链 CHAIN_XXX"，建立声尘-色尘的语义链接。

### 4.3 启发3：认知负荷 4±1 约束 → Flashcard 长度和知识点粒度控制

文档§11（工作记忆容量）引用最新研究"约 4±1 组块"，比传统的"7±2"更严格：

> "每一条讲解（声尘）或单页板书（色尘）的新要点 ≤ 4 个。讲复杂链（如封建瓦解5层因果）必须拆成'1+1递进'：先给'生产力→土地私有'（2点），固化后再加'井田制→分封制'。"

**PT-038 当前状态**：Flashcard 的 front 设计偶有"信息过载"现象（一个 front 放了3个并列问题）。

**工程改进**：
- card_generator.py 增加"单卡信息量校验"：front 的新信息点 ≤ 2，answer 的逻辑步骤 ≤ 4
- 超出则强制拆分卡片，并标注"拆分原因：超出工作记忆容量"

### 4.4 启发4："认知冲突"声尘 → 微剧本第一幕的核心问题设计

文档§11（情绪-记忆约束）给出的认知冲突声尘模板：

> "你觉得'力是维持运动的原因'很对吧？伽利略却说不对——你想想骑车不蹬还能滑一段，哪里来的力？"

**对PT-038微剧本的启发**："核心问题"应该是**真实的学术争议**，而非教科书式提问。文档的"认知冲突"恰好是PT-038"核心问题驱动"设计的认知科学依据。

**具体改进**：meta.json 的 `core_question` 字段应增加"是否包含认知冲突"的标记，只有含认知冲突的核心问题才能真正激活受蕴（乐受/好奇苦受），否则容易滑向"厌烦苦受"。

### 4.5 启发5：情境关联的"经验唤醒渠道" → 古汉语备考的关键路径

文档§1提到教师传递知识时会"结合生活实例"、"激活学生的长时记忆经验"，本质是**认知脚手架**。

**对PT-038书法备考场景的关键性**：
- 古汉语（译篆/句读）对于没有文言文阅读经验的学生，是纯形式化知识（III型），强用类比反而误导
- 但如果能唤醒学生已有的**汉字结构感知**（"看到'山'字想到三座山峰"），可以把III型转化为II型，获得受限类比的加持
- PT-038 书法配置包的"一简对多篆速查表"正是这个思路：用一个已知汉字结构（简化字）桥接到未知（篆书）
- 这说明**书法备考场景天然适合受限类比通道（II型）**，"受限"体现在"同一汉字结构可能有多种篆书写法，不强求唯一映射"

## 六、核心结论

### PT-038 的设计哲学与教学建模文档高度共鸣

PT-038 并不是在"参考"教学建模文档，而是在**实战中走到了同样的位置**：
- 音频为主（声尘）→ 微剧本
- Flashcard 强制行蕴 → 前额叶-海马体记忆回路
- 核心问题驱动 → 认知冲突激发受蕴
- Type I-IV 知识分类 → chain_type 判断 + 类比桥接

这说明**认知规律本身具有跨越项目和领域的普遍性**，好的教育产品设计迟早会向同一个理论收敛。

### PT-038 的主要缺口是"精细化"而非"方向性"

方向已经对了（声尘主格式、行蕴Flashcard、六根分工），主要缺口在：
1. **声尘精细度**：语气/节奏/停顿没有标注（影响受蕴触发质量）
2. **脑科学约束未成文**：实践中有意无意在做，但没有写成 SOP 规则
3. **类比通道未工程化**：Type I-IV 判断靠人工，SOP 应固化判定流程

### 教学建模文档给 PT-038 最有价值的三个新洞察

1. **双重编码的强制对齐要求**：不是"有声尘有图就行"，而是必须语义对齐，每条声尘必须标注对应的色尘
2. **认知冲突的精准触发**：不是"提个问题"就行，而是必须设计"你觉得X但真相是Y"这种认知落差
3. **工作记忆 4±1 的精确约束**：这比"7±2"更严格，直接影响 Flashcard 单卡信息量和 episode 结构复杂度
