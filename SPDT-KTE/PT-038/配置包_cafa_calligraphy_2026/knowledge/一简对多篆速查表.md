# 一简对多篆高频易错词速记表

> **说明**：本表是国美书法校考译篆题的核心备考资源。按「简体→篆形→辨析要点→记忆口诀→考场注意事项」编排。建议每日早晚各刷一遍，星标⭐的为必背项。

## 一、⭐⭐⭐⭐⭐ 必背高频坑词（考场必考，5组）

### 1. 斗争 → 鬥爭

| 项目 | 内容 |
|------|------|
| **简体** | 斗争 |
| **篆形** | **鬥爭** |
| **《说文》分析** | 「闘」从「鬥」（两手相持，中间有门闩），表示搏斗、争斗。会意字。量器之「斗」篆作「斗」（勺形有柄），与闘不同。 |
| **记忆口诀** | 斗争相闘用两口，量米喝酒才用斗 |
| **考场注意事项** | 考题「斗争」必写「闘爭」，写简体「斗争」0分，写量器义「斗」0分 |

### 2. 头发 → 頭髮

| 项目 | 内容 |
|------|------|
| **简体** | 头发 |
| **篆形** | **頭髮** |
| **《说文》分析** | 「髮」从「髟」（长发飘拂形）从「長」，表示毛发。发射之「發」从弓，射箭之意，两者不同。 |
| **记忆口诀** | 头上长草（髟）是头髮，拉弓射箭才出发 |
| **考场注意事项** | 考题「头发」必写「髮髮」，写「發」0分 |

### 3. 繁复 → 繁複

| 项目 | 内容 |
|------|------|
| **简体** | 繁复 |
| **篆形** | **繁複** |
| **《说文》分析** | 「複」从衣（本义：重衣、夹衣），引申为重复。往复之「復」从彳（本义：行走），表示来去。两者不同。 |
| **记忆口诀** | 穿衣重叠加複层，来去彳亍是回复 |
| **考场注意事项** | 考题「繁复」必写「複」，写「復」扣3分 |

### 4. 尘土 → 塵土

| 项目 | 内容 |
|------|------|
| **简体** | 尘土 |
| **篆形** | **塵土** |
| **《说文》分析** | 「塵」从三鹿（《说文》作「麤」，三鹿并行）从土。鹿大土小。简化尘为俗字。 |
| **记忆口诀** | 群鹿跑过扬起土，这就叫作塵 |
| **考场注意事项** | 必须写「塵」，写简体「尘」0分 |

### 5. 须 → 須

| 项目 | 内容 |
|------|------|
| **简体** | 须（需要） |
| **篆形** | **須** |
| **《说文》分析** | 「須」从页（人头）从彡（毛饰），本义：面毛也（胡须）。俗作「须」，现代简化字。 |
| **记忆口诀** | 页旁加彡是胡須，后来才变须 |
| **考场注意事项** | 写《说文》正篆「須」，写简体「须」0分 |

### 6. 云 / 雲

| 简体 | 篆形 | 辨析 | 记忆口诀 |
|------|------|------|----------|
| 古人云（说） | **云** | 从口，张口出气 | 说话曰云云，张口即言 |
| 云彩（天象） | **雲** | 从雨从云，下雨之象 | 天上下雨带雨头 |

**考场注意事项**：书法史论中「孙过庭云」「古人云」的「云」篆作「云」，表天气时篆作「雲」

## 三、高频部首篆形速查（配套记忆）

| 楷书部首 | 《说文》部名 | 小篆标准形 | 常见错误 |
|----------|-------------|-----------|----------|
| 氵（三点水） | 水部 | 水（在中/下）或水流状（在左） | 写四点？不行！ |
| 灬（四点底） | 火部 | **火**（绝对不能写四点！） | 写四点=0分 |
| 艹（草字头） | 艸部 | **艸**（两棵草） | 写「十+早」=0分 |
| 竹（竹字头） | 竹部 | **竹**（两片竹叶下垂） | 与艸不同，更圆曲 |
| 月（肉月旁） | 肉部 | **肉**（内部两横连边） | 天文「月」内横悬空不连 |

## 四、考场急救原则

> **宁可写繁，不可写简**

如果实在拿不准某个篆字，遵循以下原则：

1. **写《说文》正篆，不写简化字**：如不确定「尘」怎么写，写「塵」（《说文》有）而非「尘」（简化俗字）
2. **写部首篆形，不写楷书偏旁**：如不确定「江」的篆形，写「氵+工」而非「氵+工的楷书」
3. **优先写确定性高的部分**：如不确定「複」的声旁怎么写，先写「衣」旁确保得分
