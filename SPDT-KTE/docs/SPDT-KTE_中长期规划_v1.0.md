## P2 · 中期（3-9个月）新学科包 + 反馈闭环 + 内容扩展

**目标**：管线开始自我优化；新增学科包生产时间压缩到 3 天/卷；反馈数据开始驱动内容迭代。

### P2-1：新学科包 · PT-038-F（译篆/句读专项）

**为什么是下一个**：这是国美书法校考三科目之一（古汉语：译篆/句读），和一简对多篆速查表直接配套。PT-038 目前只有"墨骨山河"系列（书法史×历史融合），没有独立的古汉语专项包。

**PT-038-F 规划：**

| 项目 | 内容 | 说明 |
|---|---|---|
| 定位 | 译篆/句读 专项备考 | 直接对应国美古汉语科目 |
| 核心素材 | 一简对多篆速查表 | 已有，约200组对照 |
| 微剧本规划 | 4集 | ①字形演变逻辑（甲骨→金文→小篆→隶书）②六书分类判断 ③句读练习（古文标点）④译篆实操 |
| 卡片规划 | 约200张 | 译篆规则卡 + 句读判断卡 + 六书分类卡 + 链卡 |
| 知识链 | 10条 | 按字形演变 + 六书 + 句读法分类 |

**预计 v2 字段嵌入**：
- 译篆类知识节点 → `knowledge_type: II`（受限类比：简化字→篆书有多种对应）
- 句读练习类 → `knowledge_type: III`（纯形式化，关闭类比）
- 字形演变类 → `knowledge_type: I`（结构清晰，可用"汉字家族"类比）

**时间目标**：PT-038 SOP v1.2 跑通后，PT-038-F 生产时间 ≤ 3天/卷

### P2-2：新学科包 · PT-038-G（书写实践专项）

**为什么需要**：国美校考还有"书写实践"科目（现场书法创作），PT-038 目前完全没覆盖。

**PT-038-G 规划：**

| 项目 | 内容 | 说明 |
|---|---|---|
| 定位 | 书写实践 备考 | 对应现场书法考试 |
| 核心内容 | 经典碑帖技法分析 + 考试真题模拟 | 墨骨山河已有碑帖素材 |
| 微剧本规划 | 4集 | ①楷书技法（唐楷三大家）②行书技法（兰亭序·祭侄文稿）③草书基础（张旭·怀素）④书法审美判断 |
| 卡片规划 | 约180张 | 技法要点卡 + 审美判断卡 + 考试策略卡 |

**注意**：书写实践是技能类（需要动笔练习），声尘+色尘的传递效果有限——这是 PT-VFX 的色尘（笔法动态演示图）最有价值的场景。

## 优先级决策树

如果资源有限，优先做哪个？

```
资源只够做1件事
└──→ P1-1.1：PT-038 episode .py v2字段升级
      （解锁所有后续）

资源够做3件事
└──→ P1-1.1（v2字段）+ P1-1.2（转换器升级）+ P1-1.3（analogy_scene模板）
      （打通 PT-038 → PT-VFX 链路）

资源够做1个月
└──→ P1-1（墨骨山河全流程打通）
      （第一个可演示的端到端案例）

资源够做3个月
```
