> 版本：v0.1 (MVP)

## 一、产品定位

**一句话描述**：让备考学生「闭上眼睛，跟着声音临帖」。

音频版书法临帖模块是 PT-037 自适应备考平台的听觉学习入口，核心场景为：

> **「听音频讲解 → 看碑帖图片 → 跟写练习」**

与视频版的分工：

| 维度 | 音频版 | 视频版 |
|:---|:---|:---|
| 感官通道 | 听觉为主 | 视觉+听觉 |
| 干扰程度 | 无画面干扰，专注听觉 | 画面丰富，注意力分散风险 |
| 最佳场景 | 通勤、睡前、做家务、散步 | 专注自习、课堂讲解 |
| 内容形态 | MP3 + 字幕 + 碑帖图 | MP4（待制作 ep05-ep08） |
| 制作成本 | 低（已有音频素材） | 高（需视频制作） |

## 二、核心功能（音频版 MVP）

### 2.1 音频播放控制

| 功能 | 规格 |
|:---|:---|
| 播放/暂停 | 点击按钮切换，支持空格键快捷键 |
| 进度条 | 可点击跳转，可拖拽 |
| 倒退/快进 | 每次 ±15 秒 |
| 倍速播放 | 0.75x / 1x / 1.25x / 1.5x |
| 音量控制 | 滑块 0-100% |
| 记忆位置 | 关闭页面后保存播放进度，下次自动续播 |

### 2.2 字幕/讲稿同步

- **时间戳对齐**：每个字幕段落对应音频时间点（毫秒级精度）
- **自动滚动**：当前句子高亮，脚本区域自动跟随滚动
- **点击跳转**：点击任意字幕行，跳转到对应时间点
- **讲稿模式**：可切换「同步字幕」与「完整讲稿」两种视图

### 2.3 背景音乐开关

| 模式 | 说明 |
|:---|:---|
| 讲解+配乐 | 原版音频，含背景音乐（默认） |
| 纯讲解 | 去除配乐，突出人声（适合临帖时） |

> 注：当前 MVP 阶段使用同一音频文件，通过音量调节模拟，未来可接入独立音轨。

### 2.4 临帖计时器

| 功能 | 规格 |
|:---|:---|
| 预设时长 | 5 / 10 / 15 / 30 分钟 |
| 自定义时长 | 支持手动输入分钟数 |
| 倒计时显示 | 大字号居中，分钟:秒 格式 |
| 到时提醒 | 震动（手机）+ 提示音 + 视觉弹窗 |
| 暂停/继续 | 计时中可暂停，暂停不计入时长 |
| 练习记录 | 本次练习时长存入本地历史 |

## 四、与视频版的差异对比

### 4.1 用户体验差异

| 维度 | 音频版 | 视频版 |
|:---|:---|:---|
| 学习姿势 | 闭眼可学，解放双手 | 必须看屏幕 |
| 多任务兼容 | 可同时做家务、通勤、散步 | 需专注 |
| 临帖同步 | 可边听边写，无需低头看屏幕 | 可边看边写 |
| 注意力 | 听觉专注，记忆更持久（研究支持） | 视觉主导，容易疲劳 |
| 情感沉浸 | 广播剧式旁白，临场感强 | 画面辅助，理解更快 |

### 4.2 技术实现差异

| 维度 | 音频版 | 视频版 |
|:---|:---|:---|
| 文件格式 | MP3（轻量） | MP4（大文件） |
| 加载速度 | 快（1-3MB/集） | 慢（100MB+/集） |
| 离线缓存 | 易（浏览器缓存+Service Worker） | 难（大文件） |
| 字幕同步 | 纯 Web Audio API | video.currentTime 同步 |
| 响应式 | 更灵活，手机友好 | 需适配多种屏幕 |

## 五、用户旅程（UX Flow）

```
[进入临帖模块]
     ↓
[选择 EP01-EP04 中的任意一集]
     ↓
[查看碑帖配图 + 练习指引]
     ↓
[点击「开始临帖」]
     ↓
┌─────────────────────────────────┐
│  音频播放 + 字幕同步滚动          │
│  临帖计时器同步启动（可选）        │
│  碑帖配图始终可见                 │
└─────────────────────────────────┘
     ↓
[音频结束 / 计时到时]
     ↓
[显示练习总结：本集要点 + 练习时长]
     ↓
[可继续下一集 或 结束练习]
```

## 六、响应式设计要求

| 断点 | 设备 | 布局 |
|:---|:---|:---|
| < 576px | 手机竖屏 | 播放器 + 字幕，全屏紧凑 |
| 576-992px | 平板 / 手机横屏 | 左图右字幕，上下播放器 |
| > 992px | PC / 大屏平板 | 三栏：图 + 播放器 + 字幕 |

## 七、技术选型（当前 MVP）

- **纯前端**：HTML + CSS + Vanilla JS，无框架依赖
- **音频**：`HTMLAudioElement` API
- **字幕同步**：`timeupdate` 事件 + 数组遍历匹配
- **计时器**：`setInterval` + `Vibration API`
- **数据存储**：`localStorage`（进度记忆 + 历史练习）
- **图标**：内联 SVG（无外部依赖）
- **字体**：系统字体栈 + 可选 Google Fonts（思源宋体）
