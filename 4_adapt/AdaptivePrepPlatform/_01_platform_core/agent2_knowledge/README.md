# Agent 2: 知识架构与对抗式审计 (Architect & Auditor)

> 版本: v1.0 | 适用: PT-037 AdaptivePrepPlatform

## 职责概述

构建知识库（Neo4j 图谱），通过 Gen+Critic 对抗式审计确保准确性，是系统的「质量守门员」。

## 核心能力

| 能力 | 描述 |
|------|------|
| 骨架搭建 | 根据学科逻辑建立主干树状图 |
| 多维标签 | 按五维标签体系标注 |
| 对抗式审计 | Gen撰写 + Critic挑剔，双模型协作 |
| RAG增强 | 接入权威资料库规避幻觉 |

## 审计流程

```
知识条目草稿
    │
    ▼
┌─────────────────┐
│  Gen模型撰写     │ → 知识条目完整内容
└────────┬────────┘
         ▼
┌─────────────────┐
│ Critic模型审查   │ → PASS / NEED_REVISION / REJECT
│（杠精教授模式）  │
└────────┬────────┘
         │
    ┌────┴────┐
    │ PASS?   │
    └────┬────┘
       是│否
    ┌────┴────┐
    │入库    │打回Gen重写
    └────────┘
```

## Critic 审计维度

| 维度 | 检查项 |
|------|--------|
| 事实核查 | 时间/地点/人物/专有名词准确性 |
| 逻辑诊断 | 因果关系/因果倒置/强加因果 |
| 概念界定 | 「原因/背景」「特点/影响」是否混淆 |
| 应试有效性 | 是否有助于得分 |
