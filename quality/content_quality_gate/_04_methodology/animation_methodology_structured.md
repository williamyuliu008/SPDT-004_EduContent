## 一、方法论核心架构（6层）

### 第1层：概念→几何映射（知识库）

**核心理念**：人类教学经验 → 结构化知识库 → AI执行，不自由发挥。

| 组件 | 内容 | CGM对应 |
|------|------|---------|
| 基础几何元素池 | 方框（存储/集合）、圆/三角（处理/运算）、短线（关系/传递）、色块（分区） | 支柱1：语义分类学 |
| 概念类型强制规则 | 存储类=方框、处理类=圆/三角、连接=短线 | 支柱2：渲染确定性 |
| 属性绑定层 | 颜色（灰/蓝/绿）、字体（无衬线）、边框、大小比例 | 支柱2：品牌规范硬编码 |

### 第2层：动作模板库

**核心理念**：不逐帧生成，用"模板匹配+参数填充"做选择题。

| 模板类型 | 示例 | 参数 |
|---------|------|------|
| 变换类 | 旋转、平移、缩放 | 中心点、角度、偏移量 |
| 过程类 | 拆分、合并、高亮 | 顺序、时长、颜色 |
| 关系类 | 连线、对比、同步 | 节点对、样式 |
| 特殊类 | 逐步证明、数据生长、单位换算 | 领域专属参数 |

**动作选择规则**：知识点属性标签 → 匹配动作模板 → 自动填参数。不做"AI临时生成动作"。

### 第3层：知识点标签体系

**核心理念**：给每个知识点打结构化标签，用标签驱动后续所有选择。

| 标签维度 | 取值 | 驱动决策 |
|---------|------|---------|
| 呈现形式 | 动画/静态 | 选不选动画 |
| 概念类型 | 存储/处理/关系/变换 | 选什么形状 |
| 过程性 | 有过程/无过程 | 选不选动作 |
| 空间性 | 空间/非空间 | 选2D/3D |
| 复杂度 | 单步/多步 | 选模板层级 |
| 学科属性 | 数学/物理/化学/文科 | 选知识库分支 |

### 第4层：帧布局规则

**核心理念**：每帧有固定的空间布局——时间×空间×动作三个维度协同。

```
时间维度：引入帧 → 动画演示帧 → 总结帧
空间维度：核心概念区（中央）+ 辅助概念区（侧边，默认折叠）
动作维度：匹配模板库 → 自动执行
```

### 第5层：课程拆解规则

**核心理念**：整堂课 → 知识点列表 → 每个知识点按帧设计 → 串联。

```
课程大纲 → 拆知识点 → 每个知识点 = N个帧 → 帧=概念+动作+时间
                                     ↓
                              自动匹配标签+模板
```

### 第6层：规则引擎（替代自由生成）

**核心理念**：大模型只做标签匹配、选项调用——不做开放创作。

```
输入知识点 → 打标签 → 查知识库 → 匹配模板 → 填参数 → 渲染
   ↑__________规则驱动，全链路无随机____________↑
```

## 二、两阶段流程

| 阶段 | 名称 | 核心操作 | 目标 |
|------|------|---------|------|
| Phase 1 | 学习/建库 | 遍历核心概念 → AI批量打标签 → 构建知识库+模板库 | 冷启动（几千条概念，1-2周） |
| Phase 2 | 应用/生成 | 新知识点 → 自动查库 → 匹配模板 → 生成动画 | 全自动运行 |

## 三、方法论本质

**"把每步都变成选择题，不给大模型自由发挥的空间。"** 与CGM的"连续→离散"完全同构。

| CGM | 本文档方法论 |
|-----|------------|
| 约束前置 | 几何元素池锁死（只能用方框/圆/三角/短线） |
| 语义分类学 | 知识点属性标签体系（过程性/空间性/复杂度） |
| 渲染确定性 | 动作模板库（不逐帧生成，模板+参数填充） |
| 参数化接口 | 概念→几何映射规则（存储=方框，处理=圆/三角） |
| 闭环校验 | 置信度打分智能体（>90自动过，<60转人工） |

## 四、关键案例：数学动画课程

**加法交换律动画实例**：
```
输入："加法交换律"文本
  → 知识库查询：数字=方框+数字、加号=十字短线、等号=平行短线
  → 动作匹配：交换=平移模板
  → 参数填充：2个方块+3个方块→左右交换
  → 渲染：Manim自动生成
  → 输出：全自动动画视频（含几何动作+AI旁白+字幕）
```

**跨课程迁移路径**：
- 数学→物理：共用底层规则，换领域知识库+专属动作模板
- 概念类→数据类：共用标签-规则-匹配引擎，换属性定义
- 概念类→流程类：共用核心框架，换模板+布局规则

## 五、对CGM项目的价值

1. **补齐"概念→呈现"映射层**：CGM有采样（scene_type）和渲染（style_guide），缺中间的几何映射知识库
2. **动作模板即"渲染确定性"的延伸**：不仅是静态布局，还包括动画动作的选择规则
3. **标签驱动即"参数化接口"的具体化**：关键词、长度、结构→标签→形状→尺寸→文本容量
4. **三层知识库注入**= CGM支柱1+3的工程化实现
5. **置信度打分智能体**= CGM支柱5的自动化版本
