## 2. v3.0 战略主题（候选 4 方向）

### A · 4 真产品 100% 闭环

- **目标**：P-001 视频渲染管线（manim + 配音 + 字幕对齐 + 渲染）
- **价值**：4 真产品全部 P0 样本可生产 = 100% 闭环
- **当前状态**：P-001 视频 0 样本（推迟）
- **时间估算**：4 周（W27-W30）
- **风险**：
  - 渲染管线未跑过，可能有兼容性问题
  - 字幕对齐需要 STT，工具链未就位
  - 跨平台（Windows / macOS / Linux）可能踩坑
- **不做**：
  - 4 真产品 P0 样本**外**的扩产（动画精度提升等）

### B · 跨学科扩展

- **目标**：从 3 学科（历史/地理/政治）扩到 4 学科（含英语）
- **价值**：英语是高考 3 大主科之一，需求最大
- **当前状态**：3 学科 188 链 1293 卡已 ship
- **时间估算**：3-4 周（W31-W34）
- **风险**：
  - 英语 49 概念清单需新建（参考地理 49 / 政治 61 模板）
  - autoclaw 英语知识库对接（autoclaw 配置 + prompt 模板）
  - 跨学科 schema 兼容性需验证
- **不做**：
  - 5 学科扩展（化学/物理/生物也扩）—— 资源不够
  - 高考 3 主科以外（音体美等）—— 偏离定位

### C · 持续运营 cron 化

- **目标**：autoclaw 自动产新卡 → review_inbox 自动审 → ship 到 rujing
- **价值**：从"手动管理"到"无人值守"
- **当前状态**：W25 自动化已跑通（单次投递 + 自动处理）
- **时间估算**：2-3 周（W35-W37）
- **风险**：
  - autoclaw 协作出错可能污染卡库
  - 持续运营需要监控 + 异常告警
  - review_inbox 工具化（lint / status）未做
- **不做**：
  - 完全无人值守（保留 willi 拍板关键节点）

### D · review_inbox 工具化

- **目标**：tools/review_lint.py + status.py + archive.py
- **价值**：防模板漂移 + 自动 SLA 监控
- **当前状态**：review_inbox 机制（W24）+ RUJING_001 模拟样本
- **时间估算**：1-2 周
- **风险**：
  - 工具复杂度 vs 维护成本
  - 跨窗口协同时区问题
- **不做**：
  - 复杂 review 工作流引擎（保持轻量）

## 4. 我的建议（v3.0 范围）

**v3.0 主题**："**4 真产品闭环 + 跨学科扩展**"

**v3.0 包含**（按推荐顺序）：

1. **A · 4 真产品闭环**（W27-W30，4 周）
   - P-001 视频渲染管线搭建
   - 1 个 P0 样本（古史 v1 ep01）
   - 4 真产品 P0 样本**全 GOLD**
2. **B · 跨学科扩展**（W31-W34，4 周）
   - 英语学科 49 概念清单
   - autoclaw 英语知识库 prompt 模板
   - 49 链 ship 到 rujing
3. **P2 候选**（按需）：
   - C · 持续运营 cron 化（W35+）
   - D · review_inbox 工具化（W35+）

**v3.0 不做**：
- 4_adapt L2 平台层（资源未到）
- 5 学科扩展（化学/物理/生物）
- 复活已废止产品
- 高考 3 主科以外

**理由**：
- **A 优先**：100% 闭环是 v2.0 准出门的"最强实证"，P-001 视频是 4 真产品唯一缺
- **B 其次**：跨学科是覆盖面提升，"英语优先"是高考刚需
- **C/D 推迟**：C/D 是"运营效率"提升，不如 A/B 直接价值
- **风险可控**：A 的 manim 风险已知，B 的英语知识库可复用现有模板

**总时长**：8 周（2 个主轴 + 2-4 周 P2）
