## 二、架构分层说明

| 层级 | 目录 | 定位 | 成熟度 |
|:---|:---|:---|:---|
| **流水线** | 1_ingest~5_deliver | 五阶段知识加工管线 | 2/5运行中 |

| **基础设施** | shared/quality/templates | 共享工具 | — |

### 流水线阶段职责

| 阶段 | 目录 | 主要职责 | 对应SOP |
|:---|:---|:---|:---|
| 1_ingest | 知识摄入 | 考纲对齐 + ContentSpec + 领域本体消费 | M0+M1+M2 |
| 2_structure | 结构化加工 | 体裁匹配 + scene_v2 生成 + 知识图谱 | M3 |
| 3_render | 渲染生产 | 多形态渲染 + 质量门禁（阳光/灰区/失败） | M4 |
| 4_adapt | 自适应编排 | 质量记分卡 + 知识资产注册 | M5 |
| 5_deliver | 触达交付 | 人类检查点 + 多端分发 | M6 |

### 内容层职责

- **书法备考**：墨骨山河剧本杀 + 古汉语训练 + 辨析卡
- **历史备考**：古史知识链 v1~v4（60集，448张卡）

### 交付形态

```
课程内容包（products/courses/）
  → 2_structure 结构化加工（scene_v2）
  → 3_render 渲染生产（audio/video/cards）
  → 4_adapt 自适应编排（薄弱点驱动）
  → 5_deliver 触达交付（PC/手机APP）
```
