## 二、架构分层说明

| 层级 | 目录 | 定位 | PDT |
|:---|:---|:---|:---|
| **平台层** | platform/ | 编排引擎 + APP交付 + 渲染管线 | PT-037 / SPDT-014 / SPDT-KTE |
| **内容层** | products/courses/ | 按课程系列组织内容包 | 书法备考 / 历史备考 |
| **素材层** | products/PT-039/ | 书法视觉素材 | 辨析卡 / 碑帖素材 |

### 平台层职责

- **PT-037**：知识图谱 + 5Agent调度 + 自适应训练编排
- **SPDT-014**：HarmonyOS APP 交付终端（rujing/gaokao-*/thinkkit-*）
- **SPDT-KTE**：跨产品渲染管线（剧本→场景→视频/音频/卡片）

### 内容层职责

- **书法备考**：墨骨山河剧本杀 + 古汉语训练 + 辨析卡
- **历史备考**：古史知识链 v1~v4（60集，448张卡）

### 交付形态

```
课程内容包（products/courses/）
  → PT-037 编排
  → SPDT-KTE 渲染
  → SPDT-014 APP 交付
```
