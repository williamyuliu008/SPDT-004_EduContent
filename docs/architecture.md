# SPDT-004 教育内容制造 · 技术架构

> v1.0 | 2026-07-10

## 总览

SPDT-004 以 CGM（约束型生成方法论）为内核，构建教育资源全自动制造管线。

## 生产管线

```
┌─────────────────────────────────────────────────────┐
│                   INPUT LAYER                        │
│  教材/课标/文档 → Knowledge Adapter → KU 列表       │
└──────────────────────┬──────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│                  QUALITY GATE                        │
│  G-01~G-11 检查 → pass/fail + 修复建议              │
└──────────────────────┬──────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│               CONTENT GENERATION                     │
│  KU → Scene JSON → graphic_params → complexity check│
└──────────────────────┬──────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│              SHARED VIDEO FACTORY                    │
│  Manim CE 渲染 + Azure TTS 配音 + ffmpeg 合流       │
└──────────────────────┬──────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│                  DELIVERY                            │
│  成品视频 + 配套试题 + 知识图谱 → 各分发渠道         │
└─────────────────────────────────────────────────────┘
```

## 核心组件

### 1. 共享视频引擎 (shared/video_factory)

所有教育 PDT 的唯一视频生产入口。

| 组件 | 来源 | 功能 |
|---|---|---|
| Manim 渲染器 | AI_video_edu | 6 种图形类型渲染 |
| TTS 引擎 | AI_video_edu | Azure TTS 语音合成 |
| ffmpeg 合流 | AI_video_edu | 场景拼接 |
| 系列构建器 | AI_video_edu | course.yaml → 批量制作 |
| 图形参数化 | math_animation_factory | LLM JSON → Manim VGroup |

### 2. CGM 审计引擎 (quality/)

| 门禁 | 级别 | 检查项 |
|---|---|---|
| G-01~G-05 | BLOCK | statement 长度 / ku_type / scene 归属 / 重复检测 / 最小数量 |
| G-06~G-09 | WARN | ku_type 覆盖率 / 语义完整性 / 质量 / 来源质量 |
| G-11 | WARN | narration 质量 |

### 3. PDT 差异化配置

各 PDT 在共享引擎基础上做领域适配：

| PDT | 特殊知识源 | 特殊模板 | 特殊审计 |
|---|---|---|---|
| PT-030 GaokaoPrep | 国家课标 / 历年真题 | 解题模板 / 考点图谱 | 课标对齐检查 |
| PT-031 GeneralEdu | 时间线数据 / 事件库 | 年代标签 / 地理覆盖 | 事实准确度 |
| PT-032 CollegeCourseware | 数学公式 / 物理定律 | 公式推导 / 实验仿真 | 定理正确性 |
| PT-033 CorpTraining | 公司政策 / 法规 | 合规模板 / 情景模拟 | 合规性检查 |
