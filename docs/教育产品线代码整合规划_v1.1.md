## 七、核心设计原则

> **1. 平台做骨架，内容做加法**
> - 平台层（PT-037/platform/）只提供：知识引擎、叙事引擎、多形态渲染器
> - 内容层（PT-038/PT-039/PT-030~036）提供：具体科目内容
>
> **2. 一源多形**
> - 同一份剧本 JSON → 渲染器 A 输出剧本杀 / 渲染器 B 输出电子书 / 渲染器 C 输出广播剧
>
> **3. PDT 按产品线组织**
> - products/ 下每个 PT 是一个独立交付的内容包
> - 跨包共享 → shared/ 或 _cross_products/
>
> **4. 内容与资产分离**
> - 内容源码（剧本/ebook/卡片包）→ Git 管理的 PT-038/PT-039
> - 大量媒体资产（原始图/音频）→ D:/4_data/content/ 存储目录
