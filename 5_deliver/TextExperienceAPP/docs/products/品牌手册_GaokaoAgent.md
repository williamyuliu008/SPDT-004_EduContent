### 目标用户

- **核心用户**：高三考生（17–19 岁），面临高考六科复习压力
- **扩展用户**：考生家长（关注志愿填报、院校选择）
- **潜在用户**：高一高二学生（提前备考）、复读生

### 使用场景

- 六科日常刷题与智能诊断
- AI 一对一辅导与错题讲解
- 知识图谱可视化查漏补缺
- 学习数据看板追踪进步
- 高考后志愿填报辅助

### 品牌主张

> 传统教育 APP 要么是「单一学科刷题器」，要么是「臃肿的题库平台」。GaokaoAgent 以六科统一框架为底座，AI Agent 驱动诊断→辅导→图谱→看板的闭环，首版聚焦数学深度打磨，逐步扩展到全科。

### 差异化对比

| 维度 | GaokaoAgent | 传统题库 APP | 通用 AI 助手 |
|------|-------------|-------------|-------------|
| 产品形态 | AI Agent 驱动闭环 | 静态题库浏览 | 聊天式问答 |
| 学科覆盖 | 六科统一框架 | 单科/多科割裂 | 无学科深度 |
| 诊断能力 | 智能诊断 + 知识图谱 | 仅错题统计 | 无 |
| 内核复用 | common/ 22 文件共享 | 无 | N/A |
| 数据主权 | 本地优先 + API | 云端为主 | 云端 |
| 定价 | ¥18–38 买断 | 免费+广告/订阅 | 订阅制 |

## 三、智能体定位

> 依据《智能体APP设计指南》，GaokaoAgent 以**专家型智能体**为核心，以庄重、结构化的交互风格为考生提供六科 AI 辅导与志愿决策支持。

### 3.1 智能体矩阵

| APP | Agent 优先级 | 智能体类型 | 核心能力 |
|:---|:---|:---|:---|
| gaokao-agent | **P0** | 专家型 · 六科 AI 辅导 Agent | 智能诊断 → 薄弱点定位 → 知识图谱可视化 → 针对性练习 → 学习数据看板 |
| gaokao-language | **P0** | 专家型 · AI 语言伴侣 Agent | 语法纠错 → 作文智能批改 → 口语对话练习 → 阅读解析 → 词汇量评估 |
| gaokao-volunteer | P1 | 分析型 · 志愿推荐 Agent | 位次分析 → 冲稳保策略 → 院校匹配 → 录取概率测算 |

### 3.2 Agent 交互入口

| 属性 | 规范 |
|:---|:---|
| **入口形态** | 主界面**结构化卡片面板**，以学科/功能分类组织 Agent 入口，庄重有序 |
| **品牌色** | 中国红 `#C44536`，与品牌 Design Token 统一，传递权威与信赖感 |
| **触发方式** | 首页学科卡片点击 → 进入对应学科 Agent 辅导界面；志愿填报独立入口 |
| **可见性规则** | agent 和 language 全时启用 Agent 面板；volunteer 仅在高考季（6-8月）激活实时推荐引擎 |
| **设计原则** | 庄重 · 结构化 · 数据驱动——让 AI 像资深教师一样辅导备考 |

### 3.3 智能体设计原则

1. **权威感优先**: 界面采用大留白 + 清晰层级 + 数据卡片，避免花哨动画
2. **学科深度**: 每门学科拥有独立的知识图谱和诊断模型，非通用问答
3. **数据可视化**: 诊断结果以雷达图/进度条呈现，让进步可度量
4. **时效性设计**: 志愿填报 Agent 仅在高考季激活，避免全年占用注意力
