## 三、智能体定位

> 依据《智能体APP设计指南》，RhythmHabit 在核心习惯工具中嵌入**陪伴型智能体**，以温暖圆润的交互风格提供个性化习惯分析与方案调整。

### 3.1 智能体矩阵

| APP | Agent 优先级 | 智能体类型 | 核心能力 |
|:---|:---|:---|:---|
| rhythm-habit | **P1** | 陪伴型 · AI 习惯分析 Agent | 习惯数据分析 → 方案调整建议 → 断链预警 → 个性化激励策略 |
| rhythm-meditation | **P1** | 陪伴型 · 个性化推荐 Agent | 情绪感知 → 冥想场景推荐 → 时长自适应 → 呼吸节奏引导 |

### 3.2 Agent 交互入口

| 属性 | 规范 |
|:---|:---|
| **入口形态** | 页面底部**圆润卡片面板**，以**微动画**滑入，传递温暖陪伴感 |
| **品牌色** | 宁静蓝 `#3B82B0`，与品牌 Design Token 统一，搭配柔和的圆角与阴影 |
| **触发方式** | 连续打卡 3 天后自动弹出分析报告；也可点击首页 Agent 图标手动唤起 |
| **可见性规则** | 仅在 habit 和 meditation 中启用；nutrition/pomodoro/habit-game 保持纯工具体验 |
| **设计原则** | 圆润 · 温暖 · 微动画——让 AI 习惯教练像朋友一样陪伴 |

### 3.3 智能体设计原则

1. **陪伴优先**: Agent 以「习惯教练」身份出现，使用第二人称亲和对话（"你今天比昨天早起了 10 分钟！"）
2. **微动画叙事**: 面板滑入/滑出、打卡成功粒子效果、Streak 火焰动画——用细节强化正向反馈
3. **感知介入**: 仅在关键节点主动出现（连续打卡 / 即将断链 / 新纪录），避免过度打扰
4. **一致性**: 所有 Agent 交互统一使用 #3B82B0 蓝色系，圆角 12px，为整个品牌的「温暖圆润」语言定调
