# GaokaoAgent 智能体增强设计方案 v1.0

> SPDT-001 | 品牌: GaokaoAgent | 2026-07-17
> 基于 v1.0-baseline (5-tab MVP) 的 v2.0 智能体增强方案

---

## 一、基线概况

当前版本 (v1.0-baseline, commit: master) 包含：
- 5 个 Tab: 诊断/刷题/知识地图/数据面板/学科选择
- API 服务层 (`services/api.ts`) 对接 `http://127.0.0.1:8000`
- 数学精研方向，8 大知识板块，完整诊断+刷题流程
- 77 文件，~5,100 行代码

## 二、四项增强

### A: AI 问答 Tab（新增）⭐ P0

新增"AI答疑 🤖" Tab，支持自然语言输入数学题→分步讲解+同类练习推荐。

### B: AI 自适应诊断 ⭐ P1

增强现有诊断模块：从固定15题→AI动态选题，根据正确率自适应调整难度。

### C: AI 分步讲解 ⭐ P1

增强现有刷题模块：从简单对/错→AI逐步拆解解题思路，展示常见错误对比。

### D: AI 学习洞察 ⭐ P2

增强面板模块：趋势分析+考前策略+个性化练习推荐。
