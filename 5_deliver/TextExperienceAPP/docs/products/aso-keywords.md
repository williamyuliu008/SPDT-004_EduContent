# ASO 关键词策略 (App Store Optimization)

> 华为应用市场 ASO | 更新：2026-06-16 | 维护：MKT 组织部长 (mkt)

---

## 一、ASO 基础规则

### 华为应用市场搜索权重

| 因素 | 权重 | 说明 |
|------|------|------|
| 应用名称 | ⭐⭐⭐⭐⭐ | 最重要的关键词载体，前 8 个字含核心品类词 |
| 关键词标签 | ⭐⭐⭐⭐ | 后台最多 100 字符，逗号分隔 |
| 简短描述 | ⭐⭐⭐ | 80 字以内，自然包含 2-3 个核心词 |
| 完整描述 | ⭐⭐ | 前 200 字含核心词，全文自然重复 2-3 次 |
| 下载量 | ⭐⭐⭐⭐ | 下载越多排名越高 |
| 评分 & 评论 | ⭐⭐⭐ | 4 星以上有利，关键词出现在评论中也有权重 |
| 更新频率 | ⭐⭐ | 活跃更新的 App 有加权 |

## 二、各 App 关键词策略

### 2.1 极客工具箱 (craftsman-utils)

**应用名称**：`极客工具箱 - JSON正则Base64`

**关键词标签**（100 字符）：
```
JSON格式化,正则表达式测试,Base64编解码,单位换算,开发者工具,鸿蒙原生,程序员必备,离线工具
```

**简短描述**（≤ 80 字）：
```
鸿蒙原生开发者工具箱，JSON 格式化/压缩/校验，正则表达式实时测试，Base64 编解码，单位换算。纯离线，零权限。
```

**完整描述结构**：
1. 开头 200 字：JSON 格式化、正则测试、Base64、单位换算 4 大功能简述
2. 使用场景：API 调试 / 日志分析 / 编码转换 / 日常计算
3. 技术亮点：纯离线 / 零权限 / 鸿蒙原生 / 暗色模式
4. 结尾：开发者的话 + 更新承诺

**竞品词参考**：
- 直接竞品：JSON格式化工具、正则测试器、Base64编码、单位转换器
- 间接竞品：HTTPie、Postman(无鸿蒙版)、DevTools

## 三、跨 App 通用策略

### 3.1 必含通用关键词

所有 App 描述中均应自然出现的词：
- `鸿蒙原生`（差异化标识）
- `纯本地` / `离线可用`（隐私卖点）
- `无广告`（如果确实无广告）
- `零权限` / `最小权限`（隐私卖点）

### 3.2 标题公式

```
{产品名} - {品类词}{差异化修饰词}
```

例：
- `静·闪卡 - 间隔记忆复习` ← 品类词「记忆复习」+ 差异化「间隔」
- `极客工具箱 - JSON正则Base64` ← 品类词直接堆叠长尾功能

### 3.3 关键词矩阵策略

上架后 4 周的迭代策略：

| 周次 | 动作 | 目标 |
|------|------|------|
| 第 1 周 | 上架初始关键词 | 建立基础排名 |
| 第 2 周 | 看搜索词报告，替换 0 曝光词 | 提升曝光效率 |
| 第 3 周 | 发现高转化长尾词，加入标题/描述 | 抢占长尾流量 |
| 第 4 周 | 根据竞品词报告，补充差异化词 | 差异化定位 |

## 四、竞品监控

### 需要定期检查的鸿蒙竞品

| App | 竞品 | 检查频率 |
|-----|------|---------|
| craftsman-utils | 鸿蒙应用市场搜索「JSON」「正则」「Base64」 | 每月 |
| thinkkit-flashcard | 鸿蒙应用市场搜索「闪卡」「记忆」「复习」 | 每月 |
| thinkkit-zknote | 幕布(鸿蒙版)、搜索「大纲」「笔记」 | 每月 |
| rhythm-habit | Forest(鸿蒙版)、搜索「习惯」「打卡」 | 每月 |

### 竞品关键词反查方法

1. 在华为应用市场搜索品类词（如「闪卡」）
2. 观察排名前 5 的 App 的标题和描述
3. 提取其高频词作为候选关键词
4. 用「华为应用市场关键词热度查询」工具验证搜索量

## 五、关键词效果评估

### 核心指标

| 指标 | 查看位置 | 健康值 |
|------|---------|--------|
| 关键词覆盖数 | AGC → 推广 → 搜索词报告 | ≥ 50 个 |
| 关键词 Top10 占比 | AGC → 推广 → 搜索词报告 | ≥ 20% |
| 搜索下载占比 | AGC → 分析 → 下载来源 | ≥ 40% |
| 转化率（曝光→下载） | AGC → 分析 → 转化漏斗 | ≥ 15% |

## 六、笔记

- 关键词每 2-4 周迭代一次，根据搜索词报告数据驱动
- 不在标题/描述中使用 `™` `®` 符号（可能被拒）
- 不堆砌与 App 功能无关的热门词（如在不相关的 App 中用「微信」「抖音」）
- 描述中关键词密度控制在 2-5%，过高可能被判定为堆砌
- MKT 组织部长 (mkt) 为 ASO 策略的最终负责人
