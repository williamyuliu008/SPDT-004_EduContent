## 六、快速定位方法

华为开发者文档的 URL 规律：
```
开发指南: https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/{章节}
API参考:  https://developer.huawei.com/consumer/cn/doc/harmonyos-references/{模块名}
设计规范: https://developer.huawei.com/consumer/cn/doc/harmonyos-design/{章节}
```

在 `devecocli` 终端也可直接搜索：
```bash
devecocli docs "preferences"     # 搜索本地文档
devecocli docs "mindspore"       # AI 模型推理
```
