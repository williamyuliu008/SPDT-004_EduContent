## 一、上架前准备

### 1.1 APP 状态检查清单

- [ ] 编译通过（`devecocli build --build-mode release`）
- [ ] 签名通过（Release 签名，非 Debug）
- [ ] PREFLIGHT 8 项全 PASS
- [ ] 真机安装+冷启动 < 2 秒
- [ ] 核心交互可走通（至少 1 条用户路径）
- [ ] 符合品牌视觉规范（品牌色/字体/图标）

### 1.2 素材准备

| 素材 | 规格 | 说明 |
|:---|:---|:---|
| 应用图标 | 1024×1024 px, PNG | 品牌色基调，无文字 |
| 商店截图 | 竖版 1242×2688 px × 5张 | 首页/核心功能1/核心功能2/结果页/设置 |
| 宣传横幅 | 1242×2688 px | 竖版展示图 |
| 应用描述 | 中文 ≤ 4000 字 | 功能列表+亮点+更新日志 |
| 一句话简介 | ≤ 30 字 | 显示在搜索结果中 |
| 关键词 | ≤ 100 字 | 搜索词，逗号分隔 |
| 隐私政策 | URL 或文本 | 必填 |
| 权限说明 | 每项权限的使用场景 | 如"存储：用于保存笔记数据" |

### 1.3 版本管理

- `versionCode`: 自增整数（如 1000001 → 1000002）
- `versionName`: 语义化版本（如 1.0.0 → 1.0.1）
- 每次提交审核前更新 `AppScope/app.json5` 中的版本号

## 二、提交流程

### 2.1 入口

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)
2. 我的项目 → 选择对应项目（如 ThinkKit 系列）
3.  HarmonyOS 应用 → 创建应用（如已存在则选版本更新）

### 2.2 上架步骤

1. **基本信息** — 填写应用名称、一句话简介、分类、标签
2. **应用信息** — 上传图标、截图、填写描述
3. **版本信息** — 上传 Release HAP、填写版本号、更新日志
4. **隐私合规** — 隐私政策链接、权限说明
5. **提交审核** — 确认无误后提交

### 2.3 审核周期

- 首次上架: 3-7 个工作日
- 版本更新: 1-3 个工作日
- 紧急修复: 可通过加急通道（需说明原因）

### 2.4 常见拒绝原因

| 原因 | 预防措施 |
|:---|:---|
| 截图与实际不符 | 截图必须从真机截取，不得PS |
| 隐私政策缺失 | 每个APP必须提供隐私政策 |
| 功能不完整 | 核心功能必须可正常使用 |
| 品牌侵权 | 名称/图标不得模仿知名品牌 |
| 权限滥用 | 只申请实际使用的权限 |
| 崩溃/闪退 | 提交前完成真机全路径测试 |
