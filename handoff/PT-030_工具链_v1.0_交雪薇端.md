## 一、已完成工具 (4 个核心解析器)

### 1. C1 PDF 解析器 `tools/parse_pdf_exam.py`
- 入口: `python parse_pdf_exam.py <pdf_path>` 或 `--batch <dir>`
- 输出: `D:\4_data\rujing_out\真题主库\raw\<年份>_<学科>_raw.json`
- 验证: 2018 上海历史 PDF 68 题号识别, 文本提取 3969 字符 / 6 页
- 已知限制: PDF 字体编码 (GBK/latin-1) 复杂, 选项检测 0 (v1.0)

### 2. C2 v1.1 题目切分 `tools/split_questions_v11.py`
- 入口: `python split_questions_v11.py <raw_json> [<out_json>]`
- 输出: `D:\4_data\rujing_out\真题主库\split\<年份>_<学科>_split_v11.json`
- 验证: 2018 上海历史 28 题全识别 (1-28), 22 题有选项 (Q1-Q20 选择 + Q21-Q22 5选项提纲), 题型分类正确 (选择/提纲/简答/论述)
- 5 项核心改进:
  1. `split` 替代 lookahead regex (Q1 选项边界完美切分: A 考古资料/B 古本文献/C 神话传说/D 口述史料)
  2. 同行 + 分行双模式 (Q1 同行 / Q10 分行)
  3. 题号白名单 (排除 4 位数年份 1870/1910, 排除 > 35 大数字)
  4. PDF 页脚清理 (2018 上海市普通高中学业水平考试 + (历史) + 试题答案)
  5. 题型启发 (提纲/材料/论述/简答 基于分值+关键词)

### 3. docx 解析器 `tools/parse_docx_exam.py`
- 入口: `python parse_docx_exam.py <docx_path>` 或 `--batch <dir>`
- 依赖: `python-docx` (pip install python-docx)
- 验证: 2024 上海历史 docx 8 题识别, Q1/Q3/Q4/Q5 4 选项全 OK
- 优势: docx 文本结构化, 比 PDF 干净很多

### 4. doc 老试卷解析器 `tools/parse_doc_exam.py`
- 入口: `python parse_doc_exam.py <doc_path>` 或 `--batch <dir>`
- 依赖: Windows + MS Word 16.0 + `pip install pywin32`
- 验证: 1990-2017 上海历史 44 个 .doc 全部解析成功
  - 1990/1993/1998 等纯文本 doc: 35 题号 + 30+ 选项
  - 2005+ 扫描图片 doc: 题号 0-10 (因为图片, OCR 难度)
  - 总耗时 ~14s (含 Word 启动 4.9s)
- 关键技术:
  - `win32com.client.Dispatch("Word.Application")` + `Documents.Open().Content.Text`
  - 题号识别加 `\x0b` (VT vertical tab) 支持, 因 Word 用 VT 不用 LF
  - 选项 regex 末尾 `[\s　]+` 改 `[\s　]*(?=[^\s　])` 允许 0 空白
  - stdout UTF-8 wrapper 避免 `✓` 字符 GBK 编码失败

## 二、PT-030 工具链调用流程 (5 步自动化)

```
Step 1: PDF 试卷 → C1 解析 → raw.json
   python parse_pdf_exam.py "*.pdf"
        ↓
Step 2: raw.json → C2 v1.1 切分 → split.json
   python split_questions_v11.py "*_raw.json"
        ↓
Step 3 (雪薇端主导): split.json → 双 LLM 协作 → 加答案/解析/题型
   python glm5_split_review.py --input split.json
        ↓
Step 4 (雪薇端主导): split.json + LLM 输出 → 学习中心 6 学科 zhenti
   python build_zhenti_card.py --input split.json --subject 历史
        ↓
Step 5 (雪薇端主导): 学习中心 + display_target v3.0 → 学习中心/RUJING 双通道发布
```

**Step 3-5 是雪薇端工作** (按用户拍板 "知识挖掘/真题挖掘类分配给雪薇端")。
