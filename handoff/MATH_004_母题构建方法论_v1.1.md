## 5 问核心问题

### Q1：母题是否可用真题？或用真题的改变（简化，提取其中的一部分作为母题）？

**3 方案对比**：

| 方案 | 来源 | 优点 | 缺点 | 适用 |
|:---|:---|:---|:---|:---|
| A 直接用真题 | 真题原题 | 真实考情、图形现成 | 难度不可控、可能有非核心条件干扰 | 经典高频题 |
| B 真题改造/简化 | 真题为蓝本 | 难度可控、突出核心方法 | 改造后与真题有差距 | **推荐**（80% 母题） |
| C 完全原创 | 从零设计 | 精准针对薄弱点 | 易出伪命题、需要严格验证 | 补缺时用（20% 母题） |

**v1.1 推荐：方案 B（真题改造）+ C（原创补缺）**

**真题改造模板**：
```
原题（2018 上海高考历史 20 题）:
  在四棱锥 P-ABCD 中，PA⊥底面 ABCD，底面是正方形，E 是 PC 的中点。
  ①求证：BD⊥平面 PAC；
  ②若 PA = AB = 2，求点 B 到平面 PAC 的距离。

母题 pp_002（改造后）:
  已知：在四棱锥 P-ABCD 中，PA⊥底面 ABCD，底面是正方形，E 是 PC 的中点。
  已知条件: [PA ⊥ 底面] [底面正方形] [E 是 PC 中点]
  求证：BD ⊥ 平面 PAC
  核心方法: 找两条相交线法（AC 和 PA）
  
  改造点：
    - 删去 ②（点面距）—— 那是另一母题 pp_004 的内容
    - 删去 PA=AB 具体数值（不影响垂直证明）
    - 删去 E 是 PC 中点（证明中未用，仅干扰）
```

**v1.2 母题新增字段**：
- `source_type`: "真题" / "真题改造" / "原创"
- `source_ref`: "2018 上海高考历史 20 题" 或 "原创 v1.1"
- `original_problem_id`: v1.2.0 真题 ID（如果是改造）

### Q2：母题似乎缺题干，不好理解

**问题分析**：当前母题字段（v1.0）混合了"图形"和"条件"，缺独立的"题目原文"。

**当前字段问题**：
```json
"graph_bg": "在四棱锥 P-ABCD 中，PA⊥底面 ABCD，底面是正方形，E 是 PC 的中点"
```
读者无法快速分辨：哪些是已知条件？哪些是图形描述？哪些是无关信息？

**v1.1 修复方案**（拆分为 4 个独立字段）：

```json
{
  "problem_statement": "在四棱锥 P-ABCD 中，PA⊥底面 ABCD，底面是正方形，E 是 PC 的中点。求证：BD⊥平面 PAC。",
  "given_conditions": [
    "PA ⊥ 底面 ABCD",
    "底面 ABCD 是正方形",
    "E 是 PC 中点（干扰项，证明中未用）"
  ],
  "figure_description": "四棱锥 P-ABCD 底面为正方形 ABCD，PA 垂直于底面，E 在 PC 上",
  "goal": "求证：BD ⊥ 平面 PAC"
}
```

**关键差异**：
- `problem_statement` = 题目原文（自然语言）
- `given_conditions` = 结构化已知条件（每条独立）
- `figure_description` = 图形描述（仅描述图，不含条件）
- `goal` = 求证/求解目标

**v1.1 兼容**：保留 `graph_bg` 字段（拼接自上述 3 字段），旧数据不破坏。

### Q3：几何类题目需要图形，怎么办？—— 如果是真题，那么可以用真题的图，这样简单且准确

**4 方案对比**：

| 方案 | 文件 | 优点 | 缺点 | 推荐度 |
|:---|:---|:---|:---|:---|
| A ASCII 文本图 | 纯文本 | 极简、易复制 | 表达力弱（立体图难画） | ❌ |
| B SVG 矢量图 | .svg 文件 | 轻量、可缩放、可配色 | 需要手工画或工具生成 | ✅ 推荐 |
| C 位图 PNG | .png 文件 | 精确还原 | 文件大、不可缩放 | 一般 |
| D 真题原图 | 真题 PDF 截取 | 准确、权威 | 版权问题、需 PDF 工具 | ✅ 推荐（真题改造时） |

**v1.1 推荐方案 B + D 混合**：

1. **真题改造母题**：用真题原图（截取或 PDF 解析），存 `figures/<pp_id>_<source>.png`
2. **原创母题**：用工具（Mathematica / matplotlib / Asymptote）画 SVG，存 `figures/<pp_id>.svg`
3. **目录结构**：
   ```
   数学/4step/
   ├── parent_problems/pp_001.json
   ├── figures/
   │   ├── pp_001.svg          (原创母题)
   │   ├── pp_002_2018sh_20.png (真题改造)
   │   └── pp_003.svg
   ```

4. **JSON 字段引用**：
   ```json
   "figure_ref": "figures/pp_002_2018sh_20.png",
   "figure_type": "png"  // 或 "svg"
   ```

**工具链**（沿用 v1.2 已有）：
- matplotlib 画 SVG（极简数学图）
- PyMuPDF (fitz) 截取 PDF 区域作 PNG（真题原图）
- 存 `D:\4_data\knowledge_cards\数学\4step\figures\`

### Q4：母题的"合理性"如何保证？是否可能漏选、错选母题？这很严重

**4 类合理性风险**：

1. **漏选（覆盖率）**：某 chain 该有 5 母题，只选了 3
2. **错选（伪命题）**：母题结论错误或条件不充分
3. **重复（粒度错）**：2 个母题本质是同一题
4. **难度不均（分布错）**：5 母题全是基础，缺中等/压轴

**v1.1 质量门（4 道）**：

#### 门 1：覆盖率校验（链级）
```
每个 chain 必须满足：
- 母题数 ≥ 3
- 方法分布均匀（如：立体几何/线面平行 应覆盖 中位线法/平行四边形法/比例法/...）
- 难度分布：基础 + 中等 + 压轴 各 ≥ 1（如果有）
```

实现：扩展 validator 加 `chain_coverage_check()`

#### 门 2：伪命题检测（题级）
- **反向推演**：GLM-5 给定"母题 + 标准答案"，让它重新推导
  - 推导能得相同结论 → 通过
  - 推导矛盾 → FAIL，需重做
- **条件完整性**：所有 goal 中提到的"线/点"都在 given_conditions 中定义
- **逻辑链显式**：standard_steps 必须 5-8 步（不能跳过）

#### 门 3：粒度查重（链级）
- 用 GLM-5 embedding 对所有母题两两算相似度
- 相似度 > 0.85 视为重复，需合并或调整
- v1.1 可选（embedding 计算成本高）

#### 门 4：教学专家抽审（人工）
- 20% 抽样（如 15 母题抽 3）
- 教学专家（用户自己）按 5 维评分：
  - 题目正确性（无伪命题）
  - 图形准确性
  - 方法典型性
  - 难度匹配
  - 易错点完整
- 评分 ≥ 4.0 通过，< 4.0 重做

**v1.1 实施路径**：
1. W2.1：补 30 变形 + 加 4 新字段
2. W2.2：跑 GLM-5 反向推演（51 张卡）
3. W2.3：扩展 validator 加覆盖率校验
4. W2.4：教学专家抽审 20%

### Q5：母题的"易懂性"如何保证？即通过学习母题介绍材料能快速理解题目及考核点

**当前缺**：
- 题目背景故事（"为什么考这个"）
- 思路引导（"看到题后怎么想到方法"）
- 核心洞察（"题目的点睛之笔"）
- 误解汇总（"学生通常会怎么理解错"）

**v1.1 新增 3 字段**：

```json
{
  "intuition": "立体几何大题第（1）问常考'线面垂直'，本质是把抽象的'垂直'用两条相交线落地。本题底面正方形是现成的 BD⊥AC，PA⊥底面是现成的 PA⊥BD，两条线一相交，垂直就得证。",
  
  "thinking_path": "看到'求证：BD⊥面 PAC' → 想到'线面垂直判定' → 需要在面 PAC 内找两条相交线 → 面 PAC 内有 AC 和 PA → BD⊥AC（正方形）→ PA⊥BD（PA⊥底面传递）→ 完成。",
  
  "key_insight": "线面垂直判定的关键是'两条相交线'。本题两条线一条来自底面（正方形对角线垂直），一条来自侧面（PA⊥底面传递），组合起来就锁定了 BD 的方向。"

```

## 与"4 步法"前 3 步的关系

- 概念库：题干（"是什么"）→ 当前 v1.0 已 OK
- 母题库：题干 + 思路 + 洞察（"怎么解"）→ **v1.1 重点升级**
- 变形库：变形 + 触发 + 首步（"会变形"）→ 当前 v1.0 已 OK
- 综合库：4 类构题法（"会综合"）→ v2.0 范围

**母题库是 4 步法的"核心引擎"**，必须严谨、易懂、可训练。
