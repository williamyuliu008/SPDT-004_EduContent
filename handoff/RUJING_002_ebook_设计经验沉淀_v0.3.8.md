### 2.2 5 大核心方法论（移交）

#### 1. 戏剧弧线 5 幕结构
```
第一幕 开场（200-300 字反常画面 + 主角登场）
第二幕 发展（3 段【局·时间】多幕剧）
第三幕 高潮（戏剧冲突 + 因果链 5 层 + 长对话）
第四幕 转折（意外事件 + 内心独白 ≥ 100 字 + 反讽）
第五幕 收束（金句 + 历史定位 + 钩子下一章 + 考点对照表）
```

#### 2. 因果链 5 层深咬合
```
X (原因) → Y1 (直接结果) → Y2 (连锁反应) → Y3 (深层影响) → Y4 (历史定位)
```

#### 3. 文采 5 维度（节制使用）
- 画面感 / 节奏感 / 意象 / 隐喻 / 留白
- **v0.3.8 §17 逻辑优先**：细节只服务"为什么"，不独立存在

#### 4. 自动化剧本选型（v0.3.7 创新）
- LLM 决策 5 维度：时间跨度 / 主角数 / 冲突类型 / 情绪曲线 / 因果链类型
- 4 框架：A 戏剧弧线 5 幕 / B 三幕结构 / C 英雄之旅 12 段 / D Freytag 金字塔
- 1 混合：E = A+D（v0.3.7 推荐）
- v0.3.7 实战：6/7 章选 E，1/7 章选 D（ch05 甲午战争）

#### 5. 7 章统一结构（v0.3.7 试点）
```
ch00 前史（不叫"第 00 章"）+ ch01-ch05 正文 + ch06 附录（不叫"第 06 章"）
= 1 前传 + 5 正文 + 1 附录 = 7 章
每章 7-8K chars / 总 60-80K
```

### 2.3 关键技术参数

| 维度 | 参数 |
|:---|:---|
| LLM 调度 | zhipu → kimi（fail）→ qwen |
| 单次输出上限 | zhipu 4K / qwen 3.5K（**硬约束**）|
| 多 LLM 调度器 | `_llm_dispatcher.py` |
| 段生成策略 | 3 段（每段 3-3.5K）|
| v0.3.7 段数 | 段 1（开场+发展）+ 段 2（高潮+转折）+ 段 3（收束+考点对照）|
| 段间连贯性 | 段 2 prompt 注入"段 1 末尾 1500 字" |
| H1 格式 | `# 第 N 章 年代 章节`（**空格分隔，不用"，"不用"："**）|
| 字符监控 | v0.3.9 需 max_tokens=6000 + min_chars=1500 硬约束 |

## 四、高考场景核心管线方案（PT-030 高考备考）

### 4.1 高考场景的特殊性

| 维度 | 高考场景特征 |
|:---|:---|
| **目标用户** | K12 学生（高三、初三）|
| **核心痛点** | 时间紧 / 任务重 / 需要快速理解+记忆 |
| **核心诉求** | 加深理解 + 辅助记忆 + 兴趣看下去 |
| **评价标准** | 高考分数（不是阅读量）|
| **使用场景** | 碎片时间（地铁/课间）+ 深度学习（周末）|
| **交付形态** | 视频（短）+ 知识卡（碎片）+ 电子书（深度）+ 音频（通勤）|

### 4.2 PT-030 核心管线（5 模块协同）

#### Step 1：1_ingest — 知识源头（独特）

**输入**：高考课标（2020 修订）+ 6 科教材 + 历年真题 + 考纲变化
**处理**：
- M0 入口判别（学科/年级/版本）
- M1 考纲解析（考点+能力+难度）
- M2 质量校准（5 维度评分 + GOLD/SILVER/CERTIFIED）

**核心竞争力**：
- **教学专家经验**（考纲→考点→能力→难度的映射）
- **5 维度评分**（不是 LLM 自由生成）
- 课标对接（**这是他人做不来的**）

#### Step 2：2_structure — 知识卡规范（核心 ⭐）

**输入**：1_ingest 产出的考点清单
**处理**：
- v1.2.0 知识卡规范（chain.json + main.json + K01-K07.json）
- 6 维 O 编号（A 教育层/B 制度层/C 经济层/D 思想层/E 实践层/F 战略层）
- 5 维 O 编号 + 业务反哺 BIZ 维

**核心竞争力**：
- **v1.2.0 知识卡规范由我们定义**（用户原话）
- 1039 张子卡已 ship（历史 379 / 地理 294 / 政治 366）
- 6 维 O 编号（教育/制度/经济/思想/实践/战略）
- **教育方法论沉淀**（v1.2.0 卡片 = 专家教学经验编码）

#### Step 3：3_render — 多模态渲染（探索者，孵化后委托）

**输入**：v1.2.0 知识卡
**处理**：
- 视频渲染：Manim（数学/物理动画）
- 音频渲染：TTS 配音
- 多模态合流：ffmpeg

**当前状态**：已做出 4 集动画（ep01-04），证明技术可行
**未来定位**：
- **当前**：基础能力 + 探索路线
- **未来**：**孵化出平台能力后委托给专业媒体项目**
- 理由：媒体渲染（Manim 动画 + TTS + ffmpeg）**不是教育项目核心**

#### Step 4：4_adapt — 多模态适配（教育场景特殊 ⭐）

**输入**：1_ingest 知识源 + 2_structure 卡片 + 3_render 产物
**处理**：
- 碎片化适配（15-30 秒短视频 / 单卡片）
- 深度化适配（电子书 7 章 / 长视频）
- 多模态适配（视频+文字+音频+图）

**核心竞争力**：
- **教育场景特殊**（不是通用多模态转换）
- 必须结合"高考考点→能力→难度"映射
- **这是 SPDT-004 区别于通用媒体项目的关键**

#### Step 5：5_deliver — 手机 RUJING APP 交付（独特管道 ⭐）

**输入**：4_adapt 产出的多模态内容
**处理**：
- 手机 APP 端到端管道（已 ship 188 链 1293 卡）
- 用户学习行为数据反哺（→ 2_structure 优化卡片）
- 高考场景特殊 UI（碎片化阅读 + 进度跟踪）

**核心竞争力**：
- **从知识挖掘到手机展示的端到端管道**（他人做不来）
- 用户学习行为数据（**反哺 2_structure 知识卡规范**）
- 高考场景深度优化（不是通用 APP）
