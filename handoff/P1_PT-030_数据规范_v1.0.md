# P1 PT-030 数据入库规范 v1.0 (5 学科)

## 目的
让雪薇端按统一规范入库 PT-030 真题, 让 rujing 学习中心展示完整真题库 (含母题出处 + 策略关联).

## 真题总览 (雪薇端已入库)
- **5407 题跨 4 学科** (数学 145 + 历史 1602 + 地理 2178 + 政治 1482)
- 语/英/书法待补
- 数据位置: 雪薇端本地（共同仓 git 同步）

## PT-030 工具链 (宇兄端提供)

```bash
# 1. PDF 解析
python tools/parse_pdf_exam.py --pdf <file.pdf> --out <output.json>

# 2. docx 解析
python tools/parse_docx_exam.py --docx <file.docx> --out <output.json>

# 3. doc 解析 (win32com)
python tools/parse_doc_exam.py --doc <file.doc> --out <output.json>

# 4. 母题切分 (v1.1 同行+分行双模式)
python tools/split_questions_v11.py --input <raw.json> --out <split.json>

# 5. 双 LLM 生成 (GLM-5 + GLM-4-flash fallback)
python tools/glm5_question_gen.py --input <split.json> --out <gen.json>
python tools/glm4_flash_review.py --input <gen.json> --out <reviewed.json>

# 6. toolkit CLI
python tools/pt030_toolkit/cli.py parse-all --subject 历史 --year 2018
python tools/pt030_toolkit/cli.py review-all --subject 数学 --year 2024
```

完整 onboarding 文档: `handoff/PT-030_工具链_v1.0_完整onboarding.md` (22.8 KB, 15 章节)

## 5 学科入库 schema

### 真题 JSON (raw/split)
```json
{
  "id": "EXAM_2018_SH_math_01",
  "subject": "math",
  "year": 2018,
  "source": "上海高考 2018 数学 Q1",
  "problem_statement": "题目 (含选项 A/B/C/D)",
  "answer": "B",
  "difficulty": "中",
  "frequency": "高频",
  "type": "选择题/填空题/解答题"
}
```

### 真题关联母题 (linking)
```json
{
  "exam_id": "EXAM_2018_SH_math_01",
  "linked_mother_problem": "pp_001",
  "applicable_strategies": ["strategy_math_007"],
  "concept_ids": ["concept_01"]
}
```

## 双窗口协作流

```
雪薇端 (学生)                        宇兄端 (开发)
  │
  ├── 1. 收集真题 (PDF/docx)  ────► 提供 pt030_toolkit 工具链
  │
  ├── 2. 解析 + 切分              ────► 修复 bug, 增强 v1.1 双模式
  │
  ├── 3. LLM 生成母题候选        ────► GLM-4-flash fallback 修 reasoning bug
  │
  ├── 4. 人工 review + 入库      ────► validator 校验
  │
  ├── 5. rujing 试跑验收          ────► P1 验收清单 (本文件)
  │
  └── 6. 反馈 issues            ◄──── 修 P0-D bugs / 扩展工具
```
