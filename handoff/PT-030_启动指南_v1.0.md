## 三、PT-030 自动化 5 步流程（雪薇端执行）

### 步骤 1：原始 PDF/Word 解析

**输入**：`D:\9_archive\上海高考试卷\上海高考<学科>1990-2025\*.pdf/*.doc`
**工具**（**待宇兄端开发**，高难度）：
- `parse_pdf_exam.py` — 解析 PDF 试卷（题目 + 选项 + 答案 + 解析）
- `parse_docx_exam.py` — 解析 doc 试卷（兼容老试卷）
**输出**：`raw/<年份>_<学科>_raw.json`（每套试卷 1 个文件）

**临时方案**（宇兄端 PDF 解析器未就绪前）：
- 手工标注或 OCR 工具（雪薇端 9-13 启动前可先用此）

### 步骤 2：题目切分

**输入**：`raw/<年份>_<学科>_raw.json`
**工具**（**待宇兄端开发**，高难度）：
- `split_questions.py` — 切分（按题号 + 选项 + 答案）
**输出**：`split/<年份>_<学科>_split.json`（每题 1 个 JSON 对象）

### 步骤 3：GLM-5 出题（已有 v1.1 11 字段模板）

**输入**：`split/<年份>_<学科>_split.json`
**工具**：zhipu GLM-5 API（已验证 5 维评分 4.80）
**Prompt 模板**：共同仓 `prompts/01_llm_content_generation/math_4step_generate_prompt.md`
**输出**：`generated/<年份>_<学科>_v1.2.json`（真题卡 v1.2 字段）

### 步骤 4：GLM-4-flash 反向推演（合理性门）

**输入**：`generated/<年份>_<学科>_v1.2.json`
**工具**：共同仓 `tools/glm5_check.py`（用 glm-4-flash 绕开 GLM-5 reasoning 占满）
**输出**：每题 PASS/FAIL 标记

### 步骤 5：validator 校验（JSON schema）

**输入**：`generated/<年份>_<学科>_v1.2.json`
**工具**：共同仓 `tools/math_4step_validator.py --batch --dir <generated>`
**输出**：PASS 列表 / FAIL 错误清单

### 步骤 6：入库 + 共同仓 PR

**入库位置**：`D:\4_data\rujing_out\真题主库\<年份>_<学科>_<类型>_真题卡_v1.2_<N>题.json`
**PR**：commit + push 到共同仓 `williamyuliu008/SPDT-004_EduContent`
**display_target**：默认 `["学习中心"]`（雪薇端默认，v3.0 拍板）
