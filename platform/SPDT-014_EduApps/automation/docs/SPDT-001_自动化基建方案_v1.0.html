八、CI Cron 设置指南

OpenClaw cron 配置

通过 OpenClaw 内置 cron 调度每日 CI

# 在鸿蒙特使会话中执行： # 每日 8:00 CST 执行 ci-daily.ps1 # cron job: isolated agentTurn, 8:00 AM 亚洲/上海

也可手动创建 Windows Task Scheduler 任务：

# PowerShell (管理员权限): $action = New-ScheduledTaskAction -Execute "powershell.exe" ` -Argument "-File D:\92_products\SPDT-001_Harmony\scripts\ci-daily.ps1" $trigger = New-ScheduledTaskTrigger -Daily -At 8:00AM Register-ScheduledTask -TaskName "SPDT-001-DailyCI" ` -Action $action -Trigger $trigger -RunLevel Highest
