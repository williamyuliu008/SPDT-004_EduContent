## 四大能力升级

### ① AI 生成闪卡（消除手动输入摩擦）

```
传统闪卡：用户手动输入「正面/背面」→ 效率瓶颈
智能生成：「函数单调性」→ Agent 自动生成 5 张卡片：

  正面：「如何判断 f(x) 在区间上的单调性？」
  背面：「求导 f'(x)，若 f'(x)>0 则递增，<0 则递减」

  正面：「f'(x)>0 一定意味着 f(x) 递增吗？」
  背面：「是的，但反过来不一定——f(x) 递增时 f'(x) 可能为 0」

技术实现：
  考点名称 + 知识底座(kb.json) → Pipe-Filter →
  NLP 扩展 → 正反面配对 → 输出卡片组
```

**数据源**：复用 GaokaoAgent 的 `math/kb.json`（120 考点 + 方法 + 陷阱）

### ② 知识全景图（建立体系化结构）

```
不仅仅是雷达图——三层递进视图：

  L1 全景雷达（已有 HRadarChart）
     8 大板块掌握度一览

  L2 板块树状地图（新增）
     函数与导数
     ├── 函数定义域 🟢 95%
     ├── 单调性判断 🟢 85%
     ├── 极值与最值 🟡 70%
     │   ├── 极值点判定  🟢
     │   └── 含参讨论    🔴 ← 薄弱！

  L3 考点详情卡（新增）
```

**技术实现**：复用 `thinkkit-zknote` 的层级大纲组件，加上三色标记

### ③ 凌空刷题 + 拍照批改（从理解到检验）

```
完整学习闭环：

  概念理解 ──→ 思路对齐 ──→ 书写练习 ──→ 拍照批改
  (AI讲解)    (凌空刷题)   (纸上做题)   (相机OCR)
     │            │                        │
     └── 复用 ────┘                        └── 二期特性

一期（已具备）：
  凌空刷题模式 = GaokaoAgent /tutoring 页面
  「写出你的思路」→ AI 判断方向 → 鼓励型反馈 → 变式推荐
  
二期（技术储备）：
  学生纸上做完 → 拍照 → HarmonyOS OCR API →
  识别手写内容 → 与标准答案对比 → 指出错误步骤

拍照批改的独特价值：
  - 弥补手机端不便输入公式的短板
  - 保留纸笔练习的「手感」
  - AI 可以定位错误步骤而非只判对错
```

### ④ 学习模板（章节化渐进引导）

```
数学每一章都有固定的「认知阶梯」。用模板固化这个结构：

模板：「函数与导数」章节

  ┌──────────────────────────────────────┐
  │ Step 1: 概念直觉 (5分钟)              │
  │ 「导数是什么？想象你在开车——          │
  │   速度表上的数字就是位置的导数」       │  ← 经典比喻
  │ [🎯 核心要点]                         │
  │  • 导数 = 瞬时变化率                  │
  │  • 切线斜率 = 该点的导数值            │
  ├──────────────────────────────────────┤
  │ Step 2: 公式推导 (10分钟)             │
  │ 从定义出发：f'(x)=lim[Δx→0]Δy/Δx    │
  │ → 推出 (xⁿ)' = nxⁿ⁻¹               │
  │ → 推出 (sin x)' = cos x             │
  │ [✏️ 凌空刷题：推导思路检查]           │
  ├──────────────────────────────────────┤
  │ Step 3: 经典例题 (15分钟)             │
  │ 例题 1: f(x)=x³-3x+1 求极值 (★★)    │  ← 考察层次标注
  │ 例题 2: 含参讨论 (★★★★)              │
  │ [💡 出题者视角]                       │
  │ 「这道题考察的是你对 f'(x)=0 解的     │
  │   个数与参数 a 的关系是否清楚」       │
  ├──────────────────────────────────────┤
  │ Step 4: 变式训练 (10分钟)             │
  │ 同考点换数字 / 加陷阱 / 逆问题        │
  ├──────────────────────────────────────┤
  │ Step 5: 章节检测 (10分钟)             │
  │ 5 道综合题 → 三色画像更新             │
  └──────────────────────────────────────┘

每个章节 = 一个 YAML 模板文件：
  domains/math/templates/function_derivative.yaml
```

## 四合一后的完整用户旅程

```
学生打开 App
    │
    ▼
「我想提高函数与导数」
    │
    ├─→ Agent 生成学习计划 (Wizard)
    │   考点：函数定义域/单调性/极值/导数应用
    │   时间：2 周 / 每天 40 分钟
    │
    ├─→ 第 1 天：进入「函数定义域」学习模板
    │   ├─ 经典比喻：定义域 = 函数的「地盘」
    │   ├─ 核心公式：分母≠0 / 根号内≥0 / 对数真数>0
    │   ├─ 凌空刷题：「求 f(x)=√(x-1)/ln(x) 定义域 → 写出思路」
    │   └─ AI 反馈：「注意了两个限制条件，思路正确！」
    │
    ├─→ Agent：「定义域掌握度 90% → 明天进入单调性」
    │
    ├─→ 第 3 天：进入「极值与最值」学习模板
    │   ├─ 经典比喻：极值 = 山丘的「峰顶」和「谷底」
    │   ├─ 经典例题：「f(x)=x³-3x+1 的极值点」
    │   ├─ 凌空刷题：思路提交 → AI：「注意检查驻点是否为极值点」
    │   ├─ 变式训练：含参版本 → 发现薄弱
    │   └─ Agent 标记：「含参讨论 🔴 → 需要额外练习」
    │
    ├─→ 第 5 天：Agent 自动生成闪卡
    │   正面：「极值点检查：驻点 f'(x)=0，还需要验证____？」
    │   背面：「二阶导数符号或一阶导数变号」
    │
    ├─→ ... 2 周后 ...
    │
    └─→ 诊断测试 → 掌握度：函数与导数 85% ↑ +23%
        Agent：「恭喜！建议下一阶段：解析几何」
```
