## 一、AI 编码友好度筛选标准

在候选爆款中，按下表打分，**AI 友好度总分 ≥ 4 分优先做**：

| 评判维度 | 高分特征（✅ 优选） | 低分特征（❌ 回避） | 权重 |
|----------|-------------------|-------------------|------|
| **数据模式** | CRUD 为主（增删改查列表 + 详情） | 富文本块编辑器、双链图谱 | 25% |
| **UI 复杂度** | 标准声明式布局（List/Detail/Form） | 自绘 Canvas、复杂手势 | 25% |
| **状态管理** | 局部 @State/@Link，页面独立 | 深层嵌套全局共享状态 | 20% |
| **动效要求** | 弱动效/简单过渡（渐显、缩放、翻转） | 复杂物理引擎、Lottie 多时序 | 15% |
| **存储/网络** | 本地优先（Preferences），无后端 | 实时同步、OAuth、多端协作 | 10% |
| **三方依赖** | 零或极少先 HMS Kit 基础 | 强依赖 GMS/Google Maps/Facebook SDK | 5% |

## 二、六大推荐品类深度评估

### 品类 ①：生产力 & 知识管理工具

| 评估项 | 评分 | 说明 |
|--------|------|------|
| 鸿蒙缺口 | ⭐⭐⭐⭐⭐ | 缺本地优先、无广告、双链/闪卡的知识工具 |
| AI 编码友好度 | ⭐⭐⭐⭐ | List+Detail+Form CRUD 为主，状态简单 |
| 付费潜力 | ⭐⭐⭐⭐ | 知识工作者付费意愿强，适合订阅/买断 |
| 竞品密度 | ⭐⭐⭐ | 有基础记事本，但品质化工具缺位 |
| 多端适配难度 | ⭐⭐⭐ | 列表页简单，编辑页需适配平板分栏 |

**海外参考**：Anki 闪卡、Obsidian 轻量版、Notion Outliner、Zettelkasten  
**推荐 MVP**：闪卡笔记（带 SM-2 间隔重复）+ 元服务速记卡片  
**避坑**：不做双链图谱可视化（Canvas 自绘）、不做 Block Editor（富文本复杂）  
**综合推荐**：🥇 **首选题材**（AI 生成率 85%+，已验证可跑通）

## 四、不建议做的品类（直接 pass）

| 品类 | 原因 |
|------|------|
| 社交/UGC 内容型 | 需要社区运营，小团队扛不住 |
| 即时通讯 | 强实时同步 + 大厂碾压 |
| 短视频/直播 | 带宽成本 + 审核风险 |
| 强依赖 Google 服务的 | GMS 不可用，需完全重写架构 |
| 3D 渲染/游戏 | 引擎学习成本高，非工具类 |
| 加密货币/区块链 | 合规风险高 |
| AI 聊天机器人 | 大厂/开源模型碾压，无留存 |
| 需要硬件外设配合的 | Adaptability 差，受众极小 |
