架构决策记录 (ADR)

ADR-001: APP不做LLM调用，只做消费
所有LLM由小龙虾统一发起。APP始终保持可降级运行（规则引擎 fallback）。
ADR-002: 8维模块独立，AgentEngine编排
每个维度是独立ArkTS模块。不同APP按需引入不同维度组合。
ADR-003: Phase 0-2 零LLM
所有智能体行为用规则引擎+本地数据驱动。保证降级路径原生可用。
ADR-004: 小龙虾API先mock后真实
Phase 1用Flask mock验证协议。APP侧不阻塞于后端开发。

风险

🟡 小龙虾API协议反复修改
缓解：先mock→冻结v1→只增不减
🟢 common/agent-core 过度泛型化
缓解：第2个APP接入后再提炼
🔴 LLM API审批延迟
缓解：Phase 0-2零LLM，不受影响
🟡 跨APP数据隐私
缓解：小龙虾本地运行，数据不出PC
