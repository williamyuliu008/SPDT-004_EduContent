## 一、法律框架

### 1.1 中国大陆公版判定
| 条件 | 结论 |
|:---|:---|
| 作者1976年前逝世 | ✅ 公版（版权50年保护期） |
| 书法家逝世 | 唐宋元明清绝大多数 → ✅ 公版 |
| 石刻/碑帖本体 | ✅ 无版权（文物本身） |
| **翻拍的摄影作品** | ⚠️ 有邻接权，需核查来源 |

### 1.2 可用版权模式汇总

| 版权模式 | 说明 | 示例 |
|:---|:---|:---|
| **Public Domain（公版）** | 无需任何授权 | 石刻拓本（唐代碑刻无摄影师版权时） |
| **CC0（公共领域贡献）** | 无任何权利保留，可商用 | 台北故宫博物院 Open Data |
| **CC BY 4.0** | 署名即可免费使用 | 部分国际博物馆 |
| **馆藏开放数据** | 学习引用需标注来源 | 故宫博物院数字文物库 |
| **馆藏禁止外流** | 需书面申请授权 | 部分高清原文件 |
