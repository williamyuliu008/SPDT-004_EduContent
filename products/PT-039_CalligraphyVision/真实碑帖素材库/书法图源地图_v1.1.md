### 0.2 墨迹密度分析结果（精确定位正文区）

> 方法：按1%步长扫描暗色像素（灰度<80）比例，定位正文区

#### 祭侄稿左（32539×3231 px）

```
区域      暗色比例   内容
@ 0-5%   0.000     ← 装裱空白/引首
@ 5-10%   0.045     ← 印章/边缘
@ 10-15%  0.158     ← 过渡区
@ 15-50%  0.55-0.71 ← ★ 正文密集区（含徐乾学跋文等）
@ 50-55%  0.045     ← 边缘过渡
@ 60-90%  0.02-0.09 ← 题跋区
```

#### 祭侄稿右（29528×3343 px）

```
区域      暗色比例   内容
@ 10-30%  0.070-0.105 ← 边缘/印章
@ 30-60%  0.163-0.186 ← ★ 正文最密集区（颜真卿原文）
  └→ 关键段落：撫/山作郡/原/賊/孤城/父陷子死/巢傾卵覆/天不悔禍/誰為荼毒
@ 60-90%  0.068-0.124 ← 题跋区
```

#### 赵孟頫洛神赋（37812×3543 px，CMYK→RGB）

```
区域      暗色比例   内容
@ 0-5%    0.030     ← 前隔水/印章
@ 5-10%   0.011     ← 极淡
@ 10-40%  0.034-0.051 ← 后人题跋（何心山/倪瓒等）
@ 40-85%  0.085-0.126 ← ★ 正文区（赵孟頫书法）
  └→ 关键段落：翩若惊鸿/龙/风/洛/神/明/飞/云 等40+字
@ 85-95%  0.098     ← 尾声
@ 95-100% 0.021     ← 拖尾
```
