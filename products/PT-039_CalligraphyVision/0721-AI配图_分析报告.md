## 二、两个核心方向

### 方向 A：历史叙事配图（以「虎门销烟」为例）

**解决的问题**：历史教材配图中 AI 常见的「史实幻觉」（服饰穿越、道具错位、建筑年代错误）。

**核心技术方案（三层架构）：**

| 层级 | 内容 | 技术栈 |
|:---|:---|:---|
| **本体层** | 历史视觉约束库（人物/服饰/建筑/道具）| YAML/OWL 本体论 |
| **生成层** | 文本 → Prompt → 图像 | DALL-E 3 / Stable Diffusion + Seed 锁定 |
| **校验层** | 史实幻觉检测 + 风格一致性 | CLIP/VLM + 人工专家终审 |

**历史视觉本体示例（虎门销烟）：**

```yaml
Person_LinZexu:
  costume: "清代文官二品补服（锦鸡补子）、顶戴花翎、朝珠"
  appearance: "长须、方脸、身形挺拔"
  forbidden: ["西装", "中山装", "现代眼镜", "短发"]
Site_SmokePool_Humen:
  structure: "露天土石砌销烟池，带涵闸通海"
  forbidden: ["现代混凝土泳池", "工厂烟囱", "高楼大厦"]
```

**认知优化策略：**
- 渐进式揭示（Progressive Disclosure）：全局→特写→分镜
- 视觉焦点引导（Visual Saliency）：聚光/高对比度锁定核心人物
- 情感色调注入：严肃场景用低饱和度冷蓝，胜利场景用暖金

**避坑反例库：**
- 服饰穿越 → Prompt 强制注入清代服装描述
- 道具错误 → Prompt 指定土石砌结构
- 风格不适 → 锁定教科书写实风格

### 方向 B：书法素材标准化（与本项目直接相关）

**解决的问题**：书法教学图片缺乏标准化元数据，无法自动检索、装配、校验。

**核心资源库：**
- 书法五体数据库（篆/隶/楷/行/草）
- 永字八法笔画库（带 force_diagram 力道示意图）
- 碑帖高清图库（哈佛燕京/书法数据库）

**元数据字段规范（YAML Schema）：**

```yaml
- id: string          # 唯一标识
- name: string        # 汉字/碑帖名
- unicode: string      # Unicode 码点
- radical: string      # 部首
- script_type: enum    # 篆/隶/楷/行/草
- calligrapher: string # 书家
- period: string       # 年代
- pedagogical_tags: []  # 教学标签
- difficulty_level: int # 难度等级
- stroke_count: int    # 笔画数
- structure_type: enum # 左右/上下/包围等
- source: string       # 来源
- license: enum        # CC0/公共领域/授权
- resolution: string   # 分辨率
- visual_annotations: [] # 标注信息
- force_diagram: path  # 力道示意图路径
```
