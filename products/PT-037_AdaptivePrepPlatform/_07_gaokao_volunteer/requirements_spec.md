# 高考志愿填报模块 - 功能规格说明书

## 模块概述

| 属性 | 说明 |
|:----|:----|
| 模块编号 | PT-037-07 |
| 模块名称 | 高考志愿填报助手 |
| 功能定位 | 智能推荐 + 风险评估 + 策略优化 |
| 目标用户 | 高考考生及家长 |
| 核心价值 | 降低志愿填报信息不对称，提高录取命中率 |

---

## 功能范围

### 1. 核心功能（MVP）

#### 1.1 批次定位
- 根据用户分数和省份，自动确定可报考批次（本科一批/二批/专科批）
- 显示批次线与用户分数的分差
- 标注"踩线"、"超线X分"等状态

#### 1.2 院校筛选
- 按省份、院校等级（985/211/双一流/普通）、院校类型筛选
- 支持关键词搜索院校名称
- 显示院校基础信息：排名、位置、优势学科

#### 1.3 专业查询
- 按专业类别（计算机/电子/机械/文学等）筛选
- 显示专业代码、学位类型、招生状态
- 关联学科评估等级（A+/A/B+等）

#### 1.4 录取概率评估
- 基于历史录取数据计算预估概率
- 三档风险等级：稳妥（>85%）、中等（60-85%）、激进（<60%）
- 考虑大小年波动因素

#### 1.5 智能推荐（核心）
- 三种推荐策略：
  - **分数优先**：最大化院校层次，容忍专业调剂
  - **院校优先**：优先确保目标院校，专业可妥协
  - **专业优先**：锁定目标专业，院校层次可浮动
- 生成"冲-稳-保-垫"四级结构
- 每档推荐3-5个志愿，总计12-20个

#### 1.6 志愿方案导出
- 生成标准志愿表格式
- 支持打印预览
- 导出为 PDF/Excel

## 关键算法设计

### 录取概率计算

```
输入：用户分数 S_user，省市 P，专业历史最低分 S_min

分差 = S_user - S_min

if 分差 >= 5:   概率 = 95%, 风险 = "稳妥"
elif 分差 >= 0: 概率 = 80%, 风险 = "中等"
elif 分差 >= -10: 概率 = 60%, 风险 = "中等"
elif 分差 >= -20: 概率 = 40%, 风险 = "激进"
else:           概率 = 20%, 风险 = "高风险"
```

### 推荐策略排序规则

| 策略 | 第一排序 | 第二排序 | 第三排序 |
|:-----|:---------|:---------|:---------|
| 分数优先 | 分差↑ | 院校排名↑ | 专业排名↑ |
| 院校优先 | 院校排名↑ | 分差↑ | 专业排名↑ |
| 专业优先 | 专业排名↑ | 院校排名↑ | 分差↑ |

### 分数级差结构

```
冲（Chase）: 用户分数 ~ (用户分数 - 5)
稳（Secure）: (用户分数 - 5) ~ (用户分数 - 15)
保（Safe）: (用户分数 - 15) ~ (用户分数 - 30)
垫（Buffer）: (用户分数 - 30) 以下

每档数量：冲3-5个，稳3-5个，保3-5个，垫2-3个
总志愿数：12-20个
```

## 竞品对比分析

### 与夸克高考对比

| 维度 | 夸克高考 | 本模块 |
|:-----|:---------|:-------|
| 数据覆盖 | 全量院校 | 逐步扩展 |
| 推荐算法 | 模糊匹配 | 规则引擎+可解释 |
| UI体验 | App为主 | Web+API |
| 差异化 | 流量入口 | 策略可配置+跨学科融合 |

### 与掌上高考对比

| 维度 | 掌上高考 | 本模块 |
|:-----|:---------|:-------|
| 权威性 | 官方数据源 | 官方+第三方融合 |
| 推荐逻辑 | 保守策略 | 支持激进/保守切换 |
| 特色功能 | 历年数据 | 历史去向+学科评估 |

### 本模块差异化定位

1. **策略可视化**：清楚展示"冲-稳-保"策略逻辑
2. **风险量化**：给出具体概率数值而非模糊标签
3. **可解释性**：每个推荐都有理由说明
4. **平台集成**：可与历史学科包、书法备考包联动

## 设计决策记录

| 决策 | 理由 |
|:-----|:-----|
| 使用 CSV 而非数据库 | MVP阶段快速迭代，数据量可控 |
| 概率计算用规则而非ML | 可解释性优先，ML模型需要大量标注数据 |
| "冲稳安保"四级结构 | 符合主流填报逻辑，用户认知成本低 |
| 独立API服务 | 支持多端调用，可与其他模块解耦 |
