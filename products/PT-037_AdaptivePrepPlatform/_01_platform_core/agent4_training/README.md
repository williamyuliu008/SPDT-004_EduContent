# Agent 4: 能力训练与动态出题 (Coach)

> 版本: v1.0 | 适用: PT-037 AdaptivePrepPlatform

## 职责概述

「练」的环节，实现生成式学习，根据用户画像生成训练题目和错题剧本。

## 核心方法论

### 心法-手法体系

| 能力点 | 破题心法 | 答题手法 |
|--------|----------|----------|
| A1 译篆 | 以义定形，以部推字 | 拆部首→查《说文》→组字 |
| A3 句读 | 先标人名/曰云/也矣 | 固定结构标志词逐层切分 |
| A5 名词解释 | 定性→展开→采分→评价 | 四句公式，150–200字 |

### 难度分级（Scaffolding）

| 级别 | 描述 | 示例 |
|------|------|------|
| Lv1 | 单一知识点，记忆或简单理解 | 写出「斗争」的篆书 |
| Lv2 | 双知识点关联，理解与应用 | 结合安史之乱，分析颜体风格成因 |
| Lv3 | 跨学科综合，分析与评价 | 以书法为切入点，论述唐代文人精神 |

## 错题剧本化

不记录「原因：粗心」，而是构建「微观剧本」：

```json
{
  "error_type": "译篆_一简对多篆",
  "wrong_answer": "斗争 → 斗爭",
  "correct_answer": "鬥爭",
  "script": "公元2026年，你在考场上看到「斗争」两个字，毫不犹豫地写下了简体「斗」。但正确答案是「鬥」。此刻，你需要补上「斗争之『斗』篆作『鬥』（两手相持），量器之『斗』才写作『斗』这条辨析规则。"
}
```

## 用户状态驱动

| 状态维度 | 规则 |
|----------|------|
| S < 60% | 推送Lv2变式题，每次5道 |
| C >= 8 | 推送微剧本，不生成高难度题 |
| F >= 3 | 切换闪卡复习模式 |
