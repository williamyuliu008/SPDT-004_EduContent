## 五、卡片包生成规范

基于上述索引表，后续开发知识卡片 APP 时：

```
每张卡片的 chain_id 字段，格式为：
  CHAIN_[时代]_[编号]

示例：
  H_近代_01   → CHAIN_近代危机_01（鸦片战争链）
  H_近代_07   → CHAIN_近代探索_03（辛亥革命链）
  H_现代_02   → CHAIN_现代建国_01（新民主主义革命链）
```

**卡片字段规范（对应 APP 数据模型）**：
```
card_id    : H_近代_01_01    # 链ID_节点序号
chain_id   : CHAIN_近代危机_01
front      : 鸦片战争爆发的根本原因是什么？
back_core  : 工业革命后英国需要海外市场；中英贸易长期逆差
maturity   : 🟡
note       : 偶然触发：林则徐虎门销烟（1839年）
```
